# 常见任务

读完[第一个世界](../worlds/first-world.md)和[第一个插件](../plugins/first-plugin.md)之后，你大概会带着一个具体的需求回来。这一章每篇解决一件事。

## 世界作者

| 任务                                                | 你会得到什么                           |
| --------------------------------------------------- | -------------------------------------- |
| [给世界预置任务、物品和好感](./starting-content.md) | 开局就带着任务、随身物品和人物关系     |
| [开局配点和掷骰判定](./point-buy.md)                | 开局分配属性点，有风险的行动由骰子决定 |
| [角色立绘](../worlds/portraits.md)                  | 角色有自己的立绘                       |
| [场景图](../worlds/scenes.md)                       | 地点有日夜两套背景                     |
| [合集](../ship/collections.md)                      | 世界和它需要的插件一次装好             |

## 插件作者

| 任务                                     | 你会得到什么                 |
| ---------------------------------------- | ---------------------------- |
| [给插件加界面](../plugins/ui.md)         | 侧栏面板、正文里的表单和选项 |
| [带代码的插件](../plugins/local-code.md) | 模型可以调用你写的工具       |
| [用真实模型验证](../ship/real-model.md)  | 发布前确认真实模型的表现     |

## 所有人

| 任务                                     | 你会得到什么                           |
| ---------------------------------------- | -------------------------------------- |
| [制作和分享主题](./themes.md)            | 一套自己的界面配色和样式，可以导出分享 |
| [安装插件与世界包](../start/packages.md) | 装上别人做的世界和插件                 |

## 参考内置的实现

有些需求最快的办法是照着内置插件改：

| 需求                     | 参考                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 替换叙事者               | [`narrator`](../../plugins/narrator/README.md) 和 [`chat-mode-narrator`](../../plugins/chat-mode-narrator/README.md) |
| 满足条件才出现的隐藏剧情 | [`story-events`](../../plugins/story-events/README.md)                                                               |
| 接入生图或语音服务       | [图像生成](../reference/image-generation.md)、[媒体存储](../reference/media-store.md)                                |
| 给世界加日夜和时间流逝   | [世界时间](../reference/world-time.md)                                                                               |
| 给插件或世界加一种语言   | [多语言](../reference/i18n.md)                                                                                       |

想要的任务不在这里？在 [GitHub](https://github.com/ackness/covel/issues) 提出来。
