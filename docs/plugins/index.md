# 插件是什么

插件给游戏增加行为：一种叙事方式、一套判定规则、一个任务日志、一块界面面板。世界决定内容，插件决定怎么玩。

插件是一个文件夹。最简单的插件只有一个写着配置和提示词的 Markdown 文件，不需要写代码。

## 一个插件里有什么

```text
my-plugin/
├── PLUGIN.md            说明、它依赖的能力、它贡献的工具和界面；只有它是必需的
├── README.md
├── runtimes/            可选：一个或多个运行单元
│   └── <名字>/
│       ├── RUNTIME.md   何时运行、读什么、输出什么；agent 的提示词写在正文里
│       └── handler.js   函数型运行单元的代码
└── locales/             可选：名称和界面文字的译文
```

`PLUGIN.md` 的开头是一段 YAML，声明这个包是什么；后面的正文是给模型的指令。

## 运行单元：agent 和函数

插件里真正被执行的东西叫 **runtime**（运行单元）。一个插件可以没有，可以有一个，也可以有好几个。它有两种：

| 类型         | 它是什么                                 | 适合做什么                         | 花不花模型费用 |
| ------------ | ---------------------------------------- | ---------------------------------- | -------------- |
| **agent**    | 一段提示词。模型读它，再调用工具完成任务 | 写故事、从正文里提取事实、做判断   | 花             |
| **function** | 一个 JavaScript 函数                     | 掷骰、计算、读写数据、调用外部接口 | 不花           |

经验法则：**能用确定的规则算出来的事交给函数，需要理解文字的事交给 agent。**骰子应该由函数来掷，这样结果不会被行文倒推改写。

## 什么时候运行

每个 runtime 声明自己在回合的哪个阶段运行：

| 阶段        | 时机               | 典型用途                     |
| ----------- | ------------------ | ---------------------------- |
| `setup`     | 开局，游戏开始之前 | 创建角色、初始化数据         |
| `pre-turn`  | 叙事之前           | 检索资料、预先掷骰           |
| `narrative` | 叙事               | 写这一回合的故事             |
| `post-turn` | 叙事之后           | 根据正文更新任务、行囊、关系 |
| `audit`     | 最后               | 检查和收尾                   |

前一个阶段全部完成后，下一个阶段才开始。除了按阶段自动运行，runtime 也可以由玩家点按钮手动触发，或者由一个事件触发。

## 插件之间怎样配合

插件之间不直接点名对方。一个插件说自己**提供**什么能力，另一个说自己**需要**什么能力，Covel 负责把它们接起来。能力有一个带版本号的名字，例如 `narrative-engine@2`，意思是“写故事的能力，第 1 版”。

```yaml
requires: [narrative-engine@2]
```

这一行的意思是“我需要一个能写故事的插件”，而不是“我需要名叫 narrator 的那个插件”。所以叙事者可以被替换，依赖它的插件不用改。

## 插件怎样保存数据

插件不能直接改存档。它只能提出“我想改这个”，Covel 检查之后，在回合结束时一起写入。回合失败时，不会留下改了一半的数据。

每个插件有一块自己的数据，别的插件读不到。角色、资料库这些大家共用的数据由 Covel 保管：插件可以读，想改也要先提出来。

## 选一条路

| 你的需求                               | 形式               | 从哪里开始                           |
| -------------------------------------- | ------------------ | ------------------------------------ |
| 让模型多做一件事，例如每回合补一段观察 | 只有提示词         | [只写提示词的插件](./prompt-only.md) |
| 让模型使用我自己写的工具               | 提示词加代码       | [带代码的插件](./local-code.md)      |
| 确定的规则、多个步骤配合、预置数据     | 多个 runtime       | [多个 runtime 与数据](./advanced.md) |
| 加一块面板、一张表单或一段自定义界面   | 一份描述界面的文件 | [给插件加界面](./ui.md)              |

不确定选哪个时，从[第一个插件](./first-plugin.md)开始：它生成的示例同时包含一个 agent、一个函数和一块面板。
