# Runtime manifest

> Generated by `pnpm schemas:generate` from the Zod schemas in `packages/shared/src/schemas/`. Do not edit by hand; change the schema's `.describe()` text instead.

Frontmatter of `runtimes/<id>/RUNTIME.md`, and the inline `runtime` of a root `PLUGIN.md`.

JSON Schema: [`runtime-manifest.schema.json`](../../../packages/shared/schemas/runtime-manifest.schema.json).

In the path headings below, `[]` is a list item and `.*` is a map value.

## Top-level fields

| Field         | Type                        | Required | Description                                                                                 |
| ------------- | --------------------------- | -------- | ------------------------------------------------------------------------------------------- |
| `type`        | `"agent"` or `"function"`   | yes      | `agent` drives model tool calls from the prompt body. `function` runs a JavaScript handler. |
| `description` | text (string or locale map) | no       | What the runtime does. Plain string or a locale map.                                        |
| `schedule`    | object                      | no       | When and in what order the runtime runs.                                                    |
