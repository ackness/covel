# World manifest

> Generated by `pnpm schemas:generate` from the Zod schemas in `packages/shared/src/schemas/`. Do not edit by hand; change the schema's `.describe()` text instead.

The `world.yaml` at the root of a world package.

JSON Schema: [`world-manifest.schema.json`](../../../packages/shared/schemas/world-manifest.schema.json).

In the path headings below, `[]` is a list item and `.*` is a map value.

| ---------- | -------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `preset`   | string         | no       | ID of the built-in pack a new session starts from, such as `traditional-story` or `dialogue-mode` (`packs/builtin.yaml`).                                                        |

## `dimensions.*.schema.x-derive`

| Field     | Type                        | Required | Description                                                                                                                                                                                  |
| --------- | --------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`  | `"clock.elapsedSinceStart"` | yes      | What the value is computed from. `clock.elapsedSinceStart` is the time on the world clock since the session began, in the clock's base unit: minutes on a calendar, phases on a phase clock. |
| `start`   | number                      | no       | The number when the source is 0. Default 0.                                                                                                                                                  |
| `perUnit` | number                      | no       | What one unit of the source adds to the number; negative for a countdown. Default 1.                                                                                                         |
| `min`     | number                      | no       | The number never goes below this.                                                                                                                                                            |
| `max`     | number                      | no       | The number never goes above this.                                                                                                                                                            |
| `ranges`  | list of object              | no       | Turns the number into a label: the first range that holds the number gives the value. The last range has no bounds. Without `ranges` the value is the number itself.                         |
