# World manifest

> Generated by `pnpm schemas:generate` from the Zod schemas in `packages/shared/src/schemas/`. Do not edit by hand; change the schema's `.describe()` text instead.

The `world.yaml` at the root of a world package.

JSON Schema: [`world-manifest.schema.json`](../../../packages/shared/schemas/world-manifest.schema.json).

In the path headings below, `[]` is a list item and `.*` is a map value.

## Top-level fields

| Field              | Type                        | Required | Description                                                                                                                                                   |
| ------------------ | --------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schemaVersion`    | string                      | yes      | Version of the `world.yaml` format. Example: `"1.0"`.                                                                                                         |
| `id`               | string                      | yes      | Stable world ID: lowercase letters, digits and hyphens, starting with a letter. Example: `"my-world"`.                                                        |
| `name`             | text (string or locale map) | yes      | Display name of the world.                                                                                                                                    |
| `version`          | string                      | no       | Version of the world package. Example: `"0.1.0"`.                                                                                                             |
| `summary`          | text (string or locale map) | yes      | One or two sentences shown on the world card.                                                                                                                 |
| `defaultLocale`    | string                      | yes      | Default content locale as a BCP 47 tag. A session uses it when the request sets no locale.                                                                    |
| `supportedLocales` | list of string              | no       | Locales this world provides content for.                                                                                                                      |
| `tags`             | list of string              | no       | Free-form catalogue tags, such as genre.                                                                                                                      |
| `pluginPolicy`     | object                      | no       | Which plugins a session of this world starts with. It states intent and locks nothing; the player can change the selection.                                   |
| `worldData`        | string                      | no       | Path of the world data descriptor, relative to the world root. Example: `"data/world.data.yaml"`.                                                             |
| `characterSchema`  | object                      | no       | Character types and attributes of this world. When present, sessions use it as written and no schema is generated.                                            |
| `dimensions`       | map of object               | no       | Dynamic world dimensions keyed by dimension ID. Each entry is one full definition.                                                                            |
| `dimensionSources` | map of string               | no       | Dimension ID → path of an external file that holds that one definition, relative to the world root.                                                           |
| `pluginSettings`   | map of map of any           | no       | World defaults for plugin settings, keyed `pluginId → settingKey → value`. Resolution order: player override, then this value, then the plugin's own default. |
| `defaultViewMode`  | `"stage"` or `"parsed"`     | no       | Initial view for new sessions. `stage` is the fullscreen visual-novel stage. The player's own choice wins once made.                                          |

## `pluginPolicy`

| Field           | Type           | Required | Description                                                                                                                                            |
| --------------- | -------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `presetId`      | string         | no       | ID of the pack that seeds the initial plugin selection: a built-in pack or one declared in `packs`.                                                    |
| `packs`         | list of object | no       | Packs defined by this world. A pack is a named plugin selection the player can choose before play.                                                     |
| `preferredTags` | list of string | no       | Plugin tags this world prefers, such as `mode:traditional-story`.                                                                                      |
| `avoidedTags`   | list of string | no       | Plugin tags this world avoids, such as `mode:dialogue`.                                                                                                |
| `requested`     | list of string | no       | Plugin IDs to enable by default. The player can still exclude them.                                                                                    |
| `recommended`   | list of string | no       | Plugin IDs to suggest. They are not enabled automatically.                                                                                             |
| `requires`      | list of string | no       | Contract IDs the world needs, such as `action-check@1`. Any installed provider satisfies one. A missing or ambiguous provider blocks session creation. |
