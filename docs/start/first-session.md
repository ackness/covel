# 第一局游戏

这一页带你选好世界、写下第一个行动，并确认存档可以继续。完成后，你会有一局重启应用后还能接着玩的游戏。

## 开始之前

- 已经[安装](./install.md)并打开 Covel。
- 已经[连接模型](./models.md)，连接测试通过。

## 1. 选一个世界

在世界选择页挑一个内置世界。想先看背景，可以打开世界详情；准备好了就在卡片上点“进入”。

第一次玩，推荐这样选：

- 想读故事：**雾港・裂潮纪**。
- 想看立绘和场景：**遥风学园**。
- 想要骰子、任务和背包：**末班地铁** 或 **提灯古冢・初次远征**。

> [!NOTE]
> 界面语言和世界内容的语言是两回事。界面语言只决定按钮和标签；一局游戏的内容语言在创建时确定，并且一定是这个世界已有的语言版本。

## 2. 在开局准备页开始游戏

“进入”之后是开局准备页。最上面是“开始游戏”，旁边是身份选择（玩家、主持人或旁观者，各有一句说明），下面一行写着“使用：xxx · 修改”，说明这一局会用哪个 AI，以及“使用推荐设置”。

- 世界会推荐一个**玩法**，也就是一组搭配好的插件。第一次玩直接沿用它，点“开始游戏”就行。
- 想增减插件、改世界文档，或导入导出世界状态，点“自定义开局”展开。它默认收起。
- 页面提示缺少配置时，按提示补齐，通常是 AI 还没有设置密钥；点“修改”或“去设置”就会打开“设置 → 模型”。
- 以前的存档在页面最下面的“历史存档”里，默认收起。

确认后点“开始游戏”。

## 3. 完成开场

游戏可能先要你做几件事，然后才开始讲故事：

- **创建角色**：填写或选择主角的名字、背景和属性。
- **开场选择**：有的世界会让你分配属性点，或者选一个开局。

这些表单是插件给出的，不同世界不一样。完成后，故事的第一段会出现。

## 4. 写下你的行动

在输入框里写主角要做的事，然后发送。也可以直接点正文下面的行动建议。

一个回合里你会依次看到：

1. 故事正文逐字出现。
2. 正文写完后，状态还在更新：任务、背包、好感等面板随之变化。
3. 出现“本轮已完成”。故事和本轮已完成任务的结果已经保存；故事记忆等后台任务可能仍在继续。

> [!TIP]
> 等“本轮已完成”出现后再发下一条。正文写完不等于回合结束，后面还有插件在更新状态。

想换一种显示方式，可以在“阅读”和“舞台”之间切换。

## 5. 确认可以继续

关掉 Covel 再打开，回到同一个世界。世界选择页会给出“继续上次的冒险”，点它就能从上一回合接着玩；开局准备页底部的“历史存档”里也能找到。

如果历史存档读取失败，开局准备页会显示错误和“重试”按钮。点击“重试”重新读取；这不影响开始新游戏。

到这里，一整局游戏的流程你就走完了：选世界、确认玩法、开场、行动、保存、继续。

## 回合没有按预期完成时

| 你看到的                   | 发生了什么                             | 怎么办                                                             |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| “已停止，本轮未提交”       | 你中途停止了生成，这一回合没有写入存档 | 用原来的输入重试                                                   |
| 正文出来了，但部分更新失败 | 故事已生成，个别插件的状态更新没成功   | 点“重试失败任务”：只重试失败的那几项，正文和其他已完成的结果会保留 |
| 一直没有正文               | 模型没有响应，或者模型不支持工具调用   | 回到[连接模型](./models.md)重新测试；换一个支持工具调用的模型      |
| 开局准备页点不了“开始游戏” | 还有缺失的配置                         | 按页面上的提示逐项补齐                                             |

想知道某个回合里每个插件具体做了什么，可以展开回合的执行细节；更完整的追踪在调试页面里。

## 故事正在自动推进时

故事请求继续时，界面标题栏会出现“正在推进 2 / 5”标记（舞台模式下浮在画面左上角），列出当前轮数与上限。点这个标记即可停止后续推进，已保存的故事保留。你也可以直接发送新行动或台词、主持动作或旁观者推进：系统会先停止当前自动推进，再发送新的输入；普通回合中发送对话仍会插入当前回合。

若想关闭自动推进，在“编排”面板把“自动推进轮数”设为 `0` 并保存（“从下一次输入开始生效”表示修改不影响正在进行中的这一轮）。范围见[会话设置](../reference/api.md#auto-advance)。每一轮自动推进都可能调用模型；关闭页面或断线不会停止服务端运行，请用停止按钮中止。刷新页面会恢复当前进度，不会重放已经结束的推进。

## 试一局群像或旁观

世界支持时，可以在开局准备页选择“群像对话”或“旁观”玩法。开始前请先确认[AI 分工](./models.md)里的故事与插件模型均已配置：

1. 群像沿用“玩家”身份即可；想亲自当主持人，先关闭角色创建再选“主持人”。旁观玩法选“旁观者”。身份只在开局时选择。
2. 需要 DM 口吻时，在**讲述者**的“视角”设置里选“主持人”（只改变讲述口吻，不改变你的座位身份）。
3. 进入游戏后打开“菜单 → 本局设置…”，展开“高级”查看“发言规则”。只启用内置插件时会自动生效，无需手选提供方；点开设置可选择点名、固定顺序、随机、手动或导演策略。同时启用多个策略插件时，才需要在面板中指定一个。
4. 在“编排”面板可分别保存同时发言人数、子调用数和自动推进轮数；各字段独立保存，某一项失败时保留草稿，其余已保存的设置照常生效。
5. 主持人可发送“导演指示”点名两位在场 NPC；固定顺序/随机策略也可请求额外节拍。采用手动策略时，切换“选择演员”，在“演员，每行一个名字”里逐行填写角色名或别名再发送。旁观者点击“推进”即可。
6. 点击“停止推进”或发送新行动即可中止当前的自动推进，已保存的故事保留。刷新页面仍会保留你的身份和名额设置，不会重放旧的推进建议。

| 看到什么                  | 怎么处理                                                                         |
| ------------------------- | -------------------------------------------------------------------------------- |
| 没有策略或提供方歧义/失效 | 仍可由讲述者独自推进；启用一个策略插件，或在编排设置中选择/清除旧选择            |
| 缺演员或某演员失败        | 该角色本轮不发言，其余段落照常保存；若所有角色均失败，控制权交回玩家             |
| 手选名字无效              | 核对并改用准确的在场角色名或别名后重新提交；整批不会部分调用                     |
| 导演不可用                | 未配置网关时按点名策略退化；模型调用失败时改为独自叙事，请检查 AI 分工或更换策略 |

> [!NOTE]
> 玩法组合只决定启用哪些插件以及新建游戏时的默认视图，不会覆盖你已经保存的视图，也不会替你决定游玩身份、视角或发言策略。
