# 第一局游戏

这一页带你选好世界、写下第一个行动，并确认存档可以继续。完成后，你会有一局重启应用后还能接着玩的游戏。

## 开始之前

- 已经[安装](./install.md)并打开 Covel。
- 已经[连接模型](./models.md)，连接测试通过。

## 1. 选一个世界

在世界选择页挑一个内置世界。想先看背景，可以打开世界详情；准备好了就在卡片上点“进入”。

第一次玩，推荐这样选：

- 想读故事：**雾港・裂潮纪**。
- 想看立绘和场景：**遥风学园**。
- 想要骰子、任务和行囊：**Emberback Relay** 或 **提灯古冢・初次远征**。

> [!NOTE]
> 界面语言和世界内容的语言是两回事。界面语言只决定按钮和标签；一局游戏的内容语言在创建时确定，并且一定是这个世界已有的语言版本。

## 2. 在准备页确认玩法

“进入”之后是准备页。这里决定这一局启用哪些插件。

- 世界会推荐一个**玩法包**，也就是一组搭配好的插件。第一次玩直接沿用它。
- 想增减插件，或者给某个任务换一个模型用途，展开“自定义插件与高级设置”。
- 页面提示缺少配置时，按提示补齐，通常是某个用途还没有模型。

确认后点“开始游戏”。

## 3. 完成开场

游戏可能先要你做几件事，然后才开始讲故事：

- **创建角色**：填写或选择主角的名字、背景和属性。
- **开场选择**：有的世界会让你分配属性点，或者选一个开局。

这些表单是插件给出的，不同世界不一样。完成后，故事的第一段会出现。

## 4. 写下你的行动

在输入框里写主角要做的事，然后发送。也可以直接点正文下面的行动建议。

一个回合里你会依次看到：

1. 故事正文逐字出现。
2. 正文写完后，状态还在更新：任务、行囊、好感等面板随之变化。
3. 出现“本轮已完成”。故事和本轮已完成任务的结果已经保存；故事记忆等后台任务可能仍在继续。

> [!TIP]
> 等“本轮已完成”出现后再发下一条。正文写完不等于回合结束，后面还有插件在更新状态。

想换一种显示方式，可以在解析视图和舞台视图之间切换。

## 5. 确认可以继续

关掉 Covel 再打开，回到同一个世界。世界里会列出历史存档，点“继续上次的冒险”就能从上一回合接着玩。

如果历史存档读取失败，准备页会显示错误和“重试”按钮。点击“重试”重新读取；这不影响开始新游戏。

到这里，一整局游戏的流程你就走完了：选世界、确认玩法、开场、行动、保存、继续。

## 回合没有按预期完成时

| 你看到的                   | 发生了什么                             | 怎么办                                                             |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| “已停止，本轮未提交”       | 你中途停止了生成，这一回合没有写入存档 | 用原来的输入重试                                                   |
| 正文出来了，但部分更新失败 | 故事已生成，个别插件的状态更新没成功   | 点“重试失败任务”：只重试失败的那几项，正文和其他已完成的结果会保留 |
| 一直没有正文               | 模型没有响应，或者模型不支持工具调用   | 回到[连接模型](./models.md)重新测试；换一个支持工具调用的模型      |
| 准备页点不了“开始游戏”     | 还有缺失的配置                         | 按页面上的提示逐项补齐                                             |

想知道某个回合里每个插件具体做了什么，可以展开回合的执行细节；更完整的追踪在调试页面里。

### 故事正在自动推进时

故事请求继续时，聊天和舞台界面都会显示“正在推进”，并列出本次轮数与上限。点“停止推进”即可停止后续轮；先前保存的故事保留。也可以直接发送新的话语、主持动作或旁观者推进：它会先停止旧推进，再作为新的输入发送。普通回合仍用话语插入当前回合。

在“编排”面板把“自动推进轮数”设为 0 并保存即可关闭。旁边的“从下一次输入开始生效”说明保存设置不会改变当前推进。范围见[会话设置](../reference/api.md#auto-advance)。每轮可能调用模型；关闭页面或断线不会停止服务器上的推进，请使用停止按钮。刷新会恢复当前进度，不会重启已经结束的推进。

## 试一局群像或旁观

世界允许时，在准备页选择“群像对话”或“旁观”组合。先确认[模型用途](./models.md)中的剧情与插件文本用途已有配置。

1. 群像沿用“游玩身份：玩家”即可；想当主持人，关闭角色创建并选“主持人”。旁观组合选“旁观者”。身份只在新建时选择。
2. 使用 DM 口吻时，在叙事器“视角”里选主持人；这是叙事口吻，不会改变座位身份。
3. 开始后在“加载的插件”里的“编排”查看回合策略。只有内置提供方时自动解析，无需先选策略服务；点提供方设置，选择点名、固定顺序、随机、手动或导演。多个提供方时才在面板明确选一个。
4. 在编排面板分别保存角色数、子调用数和自动推进轮数。不同字段单独保存；失败草稿保留，成功字段继续生效。
5. 主持人发“导演指示”，点名两个在场 NPC；固定顺序/随机可以继续额外节拍。手动策略时，切换“选择演员”，在“演员，每行一个名字”中逐行输入姓名或别名，再发送。旁观者改用“推进”。
6. 点击“停止推进”或发送新行动结束旧的自动链；已提交故事保留。刷新仍保留身份和保存的名额，不会重放旧的继续建议。

| 看到什么                  | 怎么处理                                                                       |
| ------------------------- | ------------------------------------------------------------------------------ |
| 没有策略或提供方歧义/失效 | 仍可独自叙事；启用一个提供方或在编排里选择/清除旧选择。                        |
| 缺演员或某演员失败        | 该角色没有贡献，其余段落仍保存；全部失败时交回玩家。                           |
| 手选名字无效              | 改用准确在场姓名/别名，重新提交；整批不会部分调用。                            |
| 导演不可用                | 没有 gateway 时按点名退化；槽/模型失败时独自叙事，检查模型用途或选择其他策略。 |

组合只选插件和世界生成默认视图，不会覆盖已保存视图，也不会替你选身份、视角或算法。
