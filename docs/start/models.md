# 连接模型

Covel 不自带模型。这一页带你添加一个服务商、填入密钥、测试连接，并确认各个用途都有模型可用。完成后，世界的准备页不再提示缺少模型。

## 开始之前

你需要以下任意一种：

- 一个模型服务商的 API 密钥，例如 DeepSeek、OpenAI、Anthropic、Google Gemini、阿里云百炼（Qwen）。
- 一个本地或自建的模型服务，接口兼容 OpenAI。

模型必须支持**工具调用**（function calling）。Covel 的插件靠工具调用来更新任务、行囊这些状态，不支持工具调用的模型无法推进游戏。

> [!IMPORTANT]
> 调用模型由服务商按用量收费，费用由你的账户承担。Covel 不经手也不代付。

## 先弄懂三个词

| 词         | 意思                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| **服务商** | 一个模型接口：一个地址，加上访问它的密钥                                |
| **模型**   | 服务商下的一个模型 ID                                                   |
| **用途**   | Covel 里的一类工作，例如写故事正文（`story`）、插件更新状态（`plugin`） |

你先添加服务商和模型，再告诉 Covel 每个用途用哪个模型。初次体验时，让所有用途共用同一个文本模型就够了。

## 1. 添加服务商和模型

打开 **设置 → 模型 → 服务商与模型**。

1. 从列表里选一个内置服务商，或者添加一个自定义服务商。内置服务商已填好官方地址；自定义服务商需要填写 API 地址。
2. 填入 API 密钥。本地服务不需要密钥时可以留空。
3. 添加模型 ID。照服务商自己的写法填，Covel 会原样发过去，不做任何改动。
   - 直接提供模型的服务商，ID 就是一个名字，例如 `qwen3.8-flash`。前面不要自己加厂商名。
   - 转发多家模型的网关（例如 OpenRouter）才用“厂商/模型名”的写法，例如 `openai/gpt-5.6-sol`。这时连同 `/` 整个填进去。

一个服务商只需要配置一次地址和密钥，可以在它下面添加多个模型。

## 2. 测试连接

在服务商详情里，对刚添加的模型点测试按钮（“测试连接和延迟”）。测试成功会显示延迟。

测试失败时，先看它报的是哪一类问题：

| 报错方向       | 通常的原因                                                   |
| -------------- | ------------------------------------------------------------ |
| 认证失败       | 密钥填错，或者密钥没有这个模型的权限                         |
| 找不到模型     | 模型 ID 拼写与服务商的不一致                                 |
| 连接超时或拒绝 | 地址填错，或者需要代理（在 **设置 → 桌面 → 网络代理** 配置） |

## 3. 检查用途分配

打开 **设置 → 模型 → 用途分配**。这里列出每个用途当前使用的服务商和模型。

- 确认写故事正文的用途和插件用途都选了你刚测试通过的模型。
- 之后想省钱或提速，可以把插件用途换成一个更便宜、更快的模型，故事用途保留更强的模型。

改动立即生效，不需要重启。

## 确认完成

回到世界选择页，在任意世界卡片上点“进入”。准备页会检查这个世界的玩法需要哪些用途：

- 没有缺失提示：模型已经就绪，可以开始[第一局游戏](./first-session.md)。
- 提示某个用途不可用：回到“用途分配”给它选一个模型，或者在准备页的“自定义插件与高级设置”里，把那个任务改用一个已经配置好的用途。

## 只有订阅，没有 API 密钥

ChatGPT 这类订阅和 API 是两回事：订阅让你在它自己的应用里聊天，Covel 需要的是 API。只有订阅时，Covel 目前不能直接用它。

想用订阅来玩，可以借助第三方转换工具，例如 [Magpie](https://github.com/yetone/magpie)。这类工具把你的订阅转成一个 API 地址，然后你在 Covel 里把它当作一个自定义服务商来添加：

1. 按那个工具自己的说明装好并登录，拿到它给出的 API 地址，以及密钥（如果有）。
2. 回到上面的[第 1 步](#1-添加服务商和模型)，添加一个自定义服务商，填入这个地址和密钥，再添加它支持的模型 ID。
3. 照[第 2 步](#2-测试连接)测试连接。

> [!IMPORTANT]
> Magpie 这类工具是第三方软件，不是 Covel 开发的，也不由 Covel 维护。它们能不能用、稳不稳定、是否符合订阅服务的使用条款，请以工具和服务方各自的说明为准。使用它们出现的问题与 Covel 无关，请向工具的作者反馈。
>
> Covel 以后可能会直接支持用订阅登录，目前还没有。

## 密钥保存在哪里

- 桌面版：明文保存在 `~/.covel/keys.env`，文件权限只允许当前用户读取。
- 网页版：保存在当前浏览器的本地存储里。
