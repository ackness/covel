# 在公开体验站上玩

这一页写给在公开体验站上玩 Covel 的玩家。体验站是有人部署在云服务器上、谁都能打开的 Covel 网页版；Covel 项目自己的体验站在 [demo.covel.cc](https://demo.covel.cc/)。读完你会知道：存档和 API 密钥存在哪里，服务器能看到什么，体验站会丢掉什么，以及怎样核对这些说法。

用桌面版，或者自己部署给自己用的网页版时，数据的去向不同，见[数据、备份与升级](./data-and-upgrade.md)。

## 怎样认出体验站

体验站的页面顶部有一条提示：“这是 Covel 的公开体验站”。提示里有两个链接：“数据和密钥怎样处理”指向这一页；另一个指向这个站点正在运行的源代码版本（运营者配置了源码地址时才有）。

关掉提示后，它在这个浏览器里不再出现。**设置 → 模型 → 服务商与模型** 里，每个服务商填写密钥的地方仍然有指向这一页的链接。

## 你的数据存在哪里

体验站上，你的存档以你的浏览器为准。服务器只在内存里放运行回合需要的临时副本，不写数据库，也不写磁盘。

| 数据                                       | 存在哪里                   | 什么时候会丢                                                       |
| ------------------------------------------ | -------------------------- | ------------------------------------------------------------------ |
| 存档：游戏状态、对话、角色、插件数据、快照 | 你的浏览器（IndexedDB）    | 清除这个网站的浏览器数据时。换浏览器、换设备、用无痕窗口也看不到它 |
| 你创建或生成的世界                         | 你的浏览器（IndexedDB）    | 同上                                                               |
| API 密钥和设置                             | 你的浏览器（localStorage） | 同上                                                               |
| 运行回合用的存档副本                       | 服务器内存                 | 服务器重启时。下一次行动会重新上传，存档不受影响                   |
| 生成的图片等媒体                           | 服务器内存；存档里只记引用 | 服务器重启时。浏览器可能还留着显示用的缓存，但不保证               |
| 长期记忆的检索索引                         | 服务器内存                 | 服务器重启时。下一次行动时重新建立，会再次调用 embedding 模型      |
| 还没跑完的后台任务的进度                   | 服务器内存                 | 服务器在任务结束前重启时。任务结束后浏览器会再保存一次             |

服务器会重启：每次部署新版本都会重启。部署在 Render 免费实例上的体验站，15 分钟没人访问就休眠，休眠也等于重启，之后第一次打开要等一分钟左右。

一个会话的存档最多 64 MiB。快到上限时页面会提醒你，到时在一个新会话里把故事接下去。

体验站目前不能导出或导入完整存档。不要在这里保存重要进度；想长期玩，请用[桌面版](./install.md)。

## API 密钥怎样被使用

1. 你在设置里填写的密钥，明文保存在这个浏览器的本地存储里。
2. 需要调用模型时，浏览器把这次请求用得到的服务商的密钥放在请求头里，经 HTTPS 发给服务器。页面刚打开、还没读到服务器的模型配置时，会发送全部已保存的密钥。
3. 服务器用密钥调用你配置的模型服务商，只在这次请求里使用它。
4. 回合结束后还要继续运行的后台任务，会在服务器内存里暂存这次请求的模型配置，其中包括密钥。它只给这个会话的这个任务用：任务开始、会话被删除，或者过了 5 分钟，就会丢弃。
5. 服务器不会把密钥写进磁盘、数据库、存档或日志。请求日志只记录请求的方法、路径和状态码。

### 谁能拿到你的密钥

| 谁                      | 能不能拿到 | 原因                                                                                                                                         |
| ----------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 其他玩家                | 不能       | 密钥只属于发出它的那个请求，服务器没有共享的密钥表。别人的会话也打不开：访问一个会话要用创建它时拿到的令牌                                   |
| 网络上的其他人          | 不能       | 体验站走 HTTPS                                                                                                                               |
| 插件作者                | 不能       | 社区插件的服务端代码要运维令牌才能启用；按项目自带的 Render 配置部署时，只有随源代码发布的内置插件。插件也不能自己决定把模型请求发往哪个地址 |
| 其他网站                | 不能       | 浏览器的同源规则隔开了它们。页面带内容安全策略（CSP），插件的网页运行在隔离的框架里，读不到本地存储                                          |
| 体验站的运营者          | 能         | 密钥必须经过服务器才能调用模型。运营者改动部署就能记录它，你没法从外面确认                                                                   |
| 托管平台（例如 Render） | 理论上能   | HTTPS 在平台的代理上解密                                                                                                                     |
| 能用你这台电脑的人      | 能         | 密钥以明文存在浏览器里                                                                                                                       |

我们已经尽力保护你的数据，但密钥毕竟要经过服务器。所以请你：

- 专门为体验创建一个临时密钥，设好消费上限，不要用主力密钥。体验站的提示、引导里的模型一步和每个服务商填写密钥的地方都会提醒这一点。
- 体验结束后，到服务商后台删除或轮换这个密钥。只在设置里删掉它，只是让这个浏览器不再保存它，密钥本身仍然有效。
- 在公共电脑上玩完，清除这个网站的浏览器数据。

## 怎样核对

- Covel 的代码完全开源。体验站提示里的源代码链接指向它正在运行的那个提交。版本号由部署平台提供（Render 的 `RENDER_GIT_COMMIT`）。
- 按项目自带的 Render 配置部署时，Render 从公开仓库自动构建，每次推送都会重新部署。步骤见[在 Render 上部署体验站](./deploy-render.md)。
- 版本号说明体验站声称在运行哪份代码。它不能证明部署没有被改动，你仍然要信任运营者。
- 上面这些规则在代码里的依据：[安全边界](../internals/security.md#host-profile)和[存储](../internals/storage.md#browser-private-protocol)。

## 遇到问题时

| 现象                         | 原因和处理                                                                                    |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| 第一次打开要等一分钟左右     | 免费实例休眠后正在启动。等它启动完再刷新                                                      |
| 之前生成的图片不见了         | 服务器重启过，图片只存在服务器内存里。存档本身没有丢                                          |
| 换了浏览器或设备，存档不见了 | 存档只在原来那个浏览器里                                                                      |
| 提示存档快到浏览器的大小上限 | 一个会话的存档最多 64 MiB。在新会话里接着玩                                                   |
| 页面顶部没有体验站提示       | 你关掉过它，或者这不是体验站。**设置 → 模型 → 服务商与模型** 里填写密钥的地方仍有这一页的链接 |
| 某个管理操作要求运维令牌     | 体验站把共享的世界目录、社区插件、诊断信息和服务端设置留给运营者                              |
