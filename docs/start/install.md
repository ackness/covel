# 安装与首次启动

这一页带你装好桌面版并打开它。完成后你会停在世界选择页，看到四个内置世界。

## 开始之前

- macOS：Apple Silicon 芯片，macOS 13 及以上。
- Windows：x64。
- 其他系统暂时没有安装包，可以[从源码运行](./run-from-source.md)。

## 1. 下载

打开 [Releases 页面](https://github.com/ackness/covel/releases/latest)，下载对应系统的安装包：macOS 是 `.dmg`，Windows 是安装程序，另有一个免安装的便携版。

每个发布都附带 `SHA256SUMS.txt`，可以用它核对下载的文件。

## 2. 安装并打开

安装包目前没有签名，系统第一次打开时会拦截。这是预期的，按下面处理一次即可。

### macOS

把 Covel 拖进“应用程序”。如果打开时提示“已损坏，无法打开”，应用并没有损坏：安装包没有签名和公证，macOS 会拦截浏览器下载的应用。点“取消”，在终端运行下面这一行，再重新打开：

```bash
xattr -dr com.apple.quarantine /Applications/Covel.app
```

### Windows

运行安装程序。如果提示“已保护你的电脑”，点“更多信息”，再点“仍要运行”。如果浏览器拦下了下载，先在下载列表里选择“保留”。

## 3. 看到世界选择页

第一次打开时会出现新手引导。你可以跟着它走，也可以点“先浏览世界”跳过，之后在世界选择页点“新手引导”随时重看。

关掉引导后，你会看到世界列表，里面有四个内置世界：

| 世界               | 玩法                                 |
| ------------------ | ------------------------------------ |
| 雾港・裂潮纪       | 传统叙事的黑暗奇幻调查               |
| 遥风学园           | 舞台模式的校园群像                   |
| Emberback Relay    | 科幻边境悬疑，英文写成，另有中文版   |
| 提灯古冢・初次远征 | 经典跑团地城探索，开局配点，掷骰检定 |

看到这个列表，安装就完成了。

> [!NOTE]
> 现在可以浏览世界，但还不能开始游戏：生成剧情需要先连接一个模型。这是下一页的内容。

## 遇到问题

| 现象                           | 处理                                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| macOS 提示“已损坏”             | 按上面的步骤运行 `xattr` 命令                                                                              |
| Windows 提示“已保护你的电脑”   | “更多信息” → “仍要运行”                                                                                    |
| 窗口打开后一直是空白或加载状态 | 查看日志 `~/.covel/data/logs/desktop.log` 和 `server.log`，位置见[数据、备份与升级](./data-and-upgrade.md) |
| 重复打开没有出现第二个窗口     | 这是正常的：Covel 只运行一个实例，再次打开会聚焦已有窗口                                                   |
