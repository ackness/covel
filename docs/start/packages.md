# 安装插件与世界包

内置的四个世界和一组插件之外，你可以安装别人做的世界和插件。这一页带你从一个 GitHub 链接装好它们，并知道装完之后要做什么。

## 去哪里找

- **[插件目录](https://github.com/covel-ai/covel-plugins)**：官方的生图、语音插件和开发示例，以及社区插件。
- **[世界目录](https://github.com/covel-ai/covel-worlds)**：官方世界示例和社区世界。

也可以直接使用作者仓库的链接。

## 安装

打开 **设置 → 插件 → 安装与管理**。

1. 在 **GitHub** 点击 **官方插件库** 或 **官方世界库**。也可以粘贴公开仓库或子目录链接，再点 **解析**。
2. 在预览里按名称、ID 或标签搜索，勾选要安装的包。
3. 核对版本、来源、提交与代码风险，再确认安装。[批量安装失败时的处理](../reference/plugin-installation.md#多包预览和批量安装)见安装参考。

**本地工具** 用于安装 ZIP、导入 SillyTavern 内容或只校验 ZIP。桌面菜单里的导入入口也会打开这个页面。

> [!WARNING]
> 插件的服务端代码**不在沙箱里运行**，它能访问你电脑上的文件和网络。被目录收录不等于经过安全审计。只安装你信任的作者的插件。

## 装完之后

| 装了什么 | 什么时候可用                                           |
| -------- | ------------------------------------------------------ |
| 世界包   | 立即可用，回到世界选择页就能看到                       |
| 插件     | 需要重启后端一次。桌面版按提示点“立即重启”，存档会保留 |

重启后端后，还需要两步才能让插件运行：

1. **启用**：在世界开局准备页的插件列表里选中它，或者由世界的玩法包带上它。
2. **授权**：没有获得可信来源自动授权的社区插件，第一次要运行代码时会弹出“授权插件操作”。授权后它才开始工作；选“暂不授权”则它暂停运行，游戏的其他部分照常。

显式授权只在本次服务启动期间有效。可信来源覆盖的代码和运行审批可以自动通过；其他社区插件在重启后会再次请求授权。

> [!NOTE]
> 官方发布、但需要另外安装的插件同样属于社区插件，不会自动启用。默认没有可信来源；如需信任某个仓库，见[可信来源](../reference/plugin-installation.md#可信来源)。

预览区会列出插件申请的权限与能力。来自“可信来源”且文件未改动、未新增能力的插件，启用后会自动通过代码与运行授权（显示“自动授权：可信来源”）；若插件新增了能力、涉及单次敏感操作或本地文件有改动，仍会弹出授权提示。详情见[可信来源](../reference/plugin-installation.md#可信来源)。

## 更新和卸载

在 **已安装** 按名称、ID 或来源搜索。点对应包的 **检查更新**可以查看有什么变化。确认的更新在后端重启后生效。

- 你在本地修改过的包不会被更新覆盖。
- 更新世界包不会自动改写已有存档的开局数据。已有存档保留自己的数据和进度；想使用新的开局数据，请新开一局。

卸载同样在“安装与管理”里操作，卸载插件后也需要重启后端。

## 遇到问题

| 现象                               | 处理                                                                                     |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| 预览里某个包不能勾选               | 看它旁边的错误：通常是它依赖的能力没有插件提供，或者它要求更高的 Covel 版本              |
| 开局准备页提示世界缺少某个插件     | 不安装也可以开始，但那个插件提供的玩法不会生效                                           |
| 开局准备页提示没有插件提供某项能力 | 可以继续开局，但会缺少那项功能（例如掷骰判定）。想补齐它，安装并启用一个提供该能力的插件 |
| 插件装了但不运行                   | 依次检查：重启了后端没有，在这一局里启用了没有，授权了没有                               |
| 下载失败                           | 在 **设置 → 桌面 → 网络代理** 配置代理，下载遵循这里的设置                               |
