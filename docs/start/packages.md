# 安装插件与世界包

内置的四个世界和一组插件之外，你可以安装别人做的世界和插件。这一页带你从一个 GitHub 链接装好它们，并知道装完之后要做什么。

## 去哪里找

- **[插件目录](https://github.com/covel-ai/covel-plugins)**：官方的生图、语音插件和开发示例，以及社区插件。
- **[世界目录](https://github.com/covel-ai/covel-worlds)**：官方世界示例和社区世界。

也可以直接使用作者仓库的链接。

## 安装

打开 **设置 → 安装与管理**。

1. 浏览社区目录，或者粘贴一个公开的 GitHub 仓库链接。链接可以指向仓库里的某个子目录。
2. 解析链接。这个目录下的插件和世界包会一起列出来。
3. 勾选要安装的内容，核对 ID、版本和来源，阅读代码风险提示，确认一次后安装。

勾选的内容会一起安装，先插件后世界。其中任何一个失败，本次已经装上的都会移除，不会留下装了一半的状态。

本地的 ZIP 包也在同一个页面导入。

> [!WARNING]
> 插件的服务端代码**不在沙箱里运行**，它能访问你电脑上的文件和网络。被目录收录不等于经过安全审计。只安装你信任的作者的插件。

## 装完之后

| 装了什么 | 什么时候可用                                           |
| -------- | ------------------------------------------------------ |
| 世界包   | 立即可用，回到世界选择页就能看到                       |
| 插件     | 需要重启后端一次。桌面版按提示点“立即重启”，存档会保留 |

重启后端后，还需要两步才能让插件运行：

1. **启用**：在世界准备页的插件列表里选中它，或者由世界的玩法包带上它。
2. **授权**：社区插件第一次要运行代码时，会弹出“授权插件操作”。授权后它才开始工作；选“暂不授权”则它暂停运行，游戏的其他部分照常。

授权只在本次服务启动期间有效。重启后端后，社区插件会再次请求授权。

> [!NOTE]
> 官方发布、但需要另外安装的插件，同样按社区插件对待：不会自动启用，也不会跳过授权。只有随 Covel 一起内置的插件不需要授权。

## 更新和卸载

在已安装的资源包旁边点“检查更新”可以查看有什么变化。确认的更新在后端重启后生效。

- 你在本地修改过的包不会被更新覆盖。
- 更新世界包不会自动改写已有存档的开局数据。已有存档保留自己的数据和进度；想使用新的开局数据，请新开一局。

卸载同样在“安装与管理”里操作，卸载插件后也需要重启后端。

## 遇到问题

| 现象                           | 处理                                                                        |
| ------------------------------ | --------------------------------------------------------------------------- |
| 预览里某个包不能勾选           | 看它旁边的错误：通常是它依赖的能力没有插件提供，或者它要求更高的 Covel 版本 |
| 准备页提示世界缺少某个插件     | 不安装也可以开始，但那个插件提供的玩法不会生效                              |
| 准备页提示没有插件提供某项能力 | 这个世界离不开那项能力（例如掷骰判定），安装一个提供它的插件后才能开始      |
| 插件装了但不运行               | 依次检查：重启了后端没有，在这一局里启用了没有，授权了没有                  |
| 下载失败                       | 在 **设置 → 桌面 → 网络代理** 配置代理，下载遵循这里的设置                  |
