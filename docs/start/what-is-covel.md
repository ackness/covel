# 认识 Covel

Covel 是一个可以直接游玩的 AI RPG，也是一套用来搭建这类游戏的框架。你输入行动，模型写出接下来的故事；任务、行囊、好感、记忆这些状态随着每个回合更新，并保存下来。

这一页用五分钟说明它由什么组成。读完后，你会知道接下来该读哪一章。

## 三层：内核、插件、世界包

Covel 把一局游戏拆成三层，各管各的事：

| 层         | 负责什么                           | 例子                                         |
| ---------- | ---------------------------------- | -------------------------------------------- |
| **世界包** | 设定和内容：这是一个什么样的世界   | 世界观、角色、规则、开局任务、立绘和场景图   |
| **插件**   | 行为：游戏怎么玩                   | 叙事者、掷骰判定、任务日志、行囊、好感、记忆 |
| **内核**   | 通用规则：谁先运行、什么能写入存档 | 安排运行顺序、检查改动、保存、显示界面       |

一句话记住它：**世界描述内容，插件实现行为，内核提供通用接口和执行规则。**

这条边界带来三个直接的好处：

- 同一个世界可以换一个叙事者，或者不启用任务系统，不需要改任何代码。
- 同一个插件可以用在很多世界里，它不需要知道自己在哪个世界。
- 你做的世界和插件是独立的包，可以单独发给别人安装。

## 一个回合里发生了什么

你发出一条行动之后：

1. 内核决定这一回合要运行哪些插件，并按阶段排好顺序：叙事之前、叙事、叙事之后、最后检查。
2. 每个插件读到它需要的内容，例如世界设定、最近的对话和它自己保存的数据。
3. 叙事插件写出故事正文，你在屏幕上看到它逐字出现。
4. 叙事之后，其他插件根据这段正文更新各自的状态：任务推进了没有，行囊里多了什么，谁对你的态度变了。
5. 内核校验所有改动，一次性写入存档。界面显示“本轮已完成”。

插件不能直接改存档。它们只能提出“我想改这个”，内核检查通过后才真正写入。所以一个回合要么完整生效，要么什么都不留下。

## 两种看故事的方式

![舞台模式：场景背景、角色立绘和对话框](/stage-mode.webp)

- **舞台模式**是全屏的视觉小说：场景背景、角色立绘、打字机对话框和选项。
- **叙事模式**是经典的文字回合：正文里带行动建议和表单，每个回合里各个插件做了什么都能展开查看。

![叙事模式：正文、行动建议和右侧面板](/text-mode.webp)

世界可以声明自己的默认方式，游戏中随时可以切换。

## 你需要准备什么

- **一台电脑**：macOS（Apple Silicon，macOS 13 及以上）或 Windows x64。
- **一个模型**：Covel 不自带模型。你需要一个服务商的 API 密钥，或者一个本地运行的、兼容 OpenAI 接口的模型服务。模型需要支持工具调用。

Covel 目前是早期版本。清单格式、世界数据和 API 可能随版本变化，升级前请先读[数据、备份与升级](./data-and-upgrade.md)。
