# 导入 SillyTavern 内容

已有 SillyTavern 角色卡或世界书时，可以把它们转成一个普通的 Covel 世界包。支持 V2、V3 和旧式平铺 JSON 角色卡，以及带 `chara` / `ccv3` 文本块的 PNG 卡。世界书可以单独导入，也可以跟多张角色卡一起导入。

这个功能用于桌面版和自部署网页版，写入服务器的用户世界目录。浏览器私有存档不能用它把世界导入 BrowserVault。

## 在应用里导入

1. 打开 **设置 → 安装与管理**，找到 **导入 SillyTavern 内容**。
2. 选择角色卡和世界书文件。一次选择的文件会合成一个世界。
3. 选择内容语言，按需填写世界名称。语言默认是界面语言，不会自动检测或翻译卡片。
4. 点击 **预览**。检查世界 ID、角色数、资料条目数、封面和按严重程度分组的报告。预览不会写入文件或创建世界记录。
5. 看过报告后点击 **导入**。成功后世界立即出现在世界列表，无需重启。修改文件、语言或名称后，需要重新预览。

具体数量、大小上限和 API 响应见 [安装 API](../reference/api.md#插件与世界安装install)。

## 角色卡怎样转换

| 原字段                                       | 导入结果                                                      |
| -------------------------------------------- | ------------------------------------------------------------- |
| `name`、V3 `nickname`                        | NPC 的名字和别名；第一张卡的名字也是默认世界名                |
| `description`、`personality`                 | 角色说明、`blueprint.persona.summary`；过长的文字会裁剪并报告 |
| `scenario`                                   | 世界正文的 Scenario；多张卡按角色分段                         |
| `first_mes`                                  | 角色蓝图的开场白；第一张卡也写进世界正文的 Opening            |
| `mes_example`                                | 按 `<START>` 和玩家 / 角色行解析为对话示例                    |
| `system_prompt`、`post_history_instructions` | 世界正文的 Narration notes；报告会明确提醒                    |
| `creator_notes`                              | 第一段只用于世界摘要，不进入世界正文或角色提示                |
| `tags`、`creator`                            | 合并的世界标签、首个非空作者                                  |
| `character_book`                             | 追加到资料库                                                  |
| 第一张 PNG 卡的图片                          | 去掉文本及其他元数据后作为封面；不是角色立绘                  |

正文没有场景、开场白和叙事备注时，用第一张卡的描述作为 Premise。只有世界书时，用第一条有效资料的正文。没有任何可用文字时，导入会失败。

## 世界书怎样转换

| 原字段                        | 导入结果                                         |
| ----------------------------- | ------------------------------------------------ |
| `keys` / `key`                | 去重的普通关键词；正则关键词会删除并报告         |
| `content`、`name` / `comment` | 资料正文、标题；空正文跳过                       |
| `constant`                    | 常驻或关键词触发；触发型条目没有普通关键词时跳过 |
| `enabled` / `disable`         | 是否启用；`disable: true` 优先                   |
| `insertion_order` / `order`   | 插入顺序                                         |
| `position`                    | 简化为插件前或插件后；不能保留的位置含义会报告   |
| `scanDepth`                   | 回看历史的深度，限定在 Covel 支持的范围          |

不保留备选开场白、群组开场白、多语言作者备注、次级关键词、概率、粘滞、冷却、分组、递归、向量搜索和其他高级匹配设置。Covel 没有对应的开场选择器或匹配机制。原条目 ID 会重新生成。扩展、脚本、正则脚本、宏脚本和其他无法映射的字段都会列进报告；不会把原始 JSON 留在包里。

## 报告与安全

报告区分信息、警告和错误，注明来源文件、字段和数量。界面翻译已知的报告代码；未知代码显示服务端的英文说明。扩展只列键名，不展示或运行脚本内容。

导入只做数据转换。不会运行 SillyTavern 扩展、脚本、正则表达式或宏。只替换角色名、玩家称呼等固定宏；其余宏删除并报告。HTML 标签、活动元素和危险链接目标会清理，普通安全链接可以保留。PNG 只读取有大小限制的普通文本块，不解压压缩文本块。

清理不能判断提示词是否可信。场景、资料和叙事备注仍会被模型读到，信任程度与其他第三方世界包相同。尤其要检查报告里的“角色卡指令已作为普通叙事备注写入世界正文”。

## 继续编辑与添加语言

结果包含 `world.yaml`、`WORLD.md`，以及有对应内容时的 `characters/characters.json`、`data/lorebook.yaml` 和 `media/gallery/cover.png`。默认选择对话玩法包，开局前可以修改选择。没有立绘、`presence.json` 或独立媒体库记录。

可以在世界详情里继续编辑世界，也可以修改用户世界目录里的这些普通文件；角色与资料格式见[世界数据](../reference/world-data.md)。只有一个语言版本，主清单的 `defaultLocale` 就是导入时选的语言。

要增加英文或其他语言，先把界面切到目标语言，在世界详情选择“翻译成〈语言〉”，检查生成的译文。现有的翻译流程会添加语言版本，不需要重新导入；详见[本地化](../reference/i18n.md)。

## 遇到问题

| 现象                                     | 怎么处理                                  |
| ---------------------------------------- | ----------------------------------------- |
| PNG 没有可用卡片文本块，或只有压缩文本块 | 从原工具导出 JSON 再导入                  |
| 角色名字清理后为空，或所有文字都不可用   | 补全名字和正文，再预览                    |
| 文件或生成的资料库超出上限               | 拆分或精简内容，查看报告和 API 限制       |
| 世界 ID 冲突                             | 重试；连续冲突时换一个世界名              |
| 预览和导入之间出现新的警告或 ID 变化     | 其他导入可能占用了 ID；以本次导入响应为准 |
