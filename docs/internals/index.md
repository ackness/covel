## 从哪里读起

想改框架时，按这个顺序读：

1. [设计原则](./design-principles.md)。先确认你要加的东西属于内核还是插件。大多数玩法需求属于插件。
2. [回合管线与数据流](./flow.md)。找到你的改动落在管线的哪一段。
3. 仓库根目录的 `AGENTS.md`。它列出了每一类改动必须同步更新的文档和要运行的检查。
