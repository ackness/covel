### Changed

- **Switching the desktop data directory can bring your data along.** After you pick a new directory in Settings → Desktop, Covel asks whether to copy your existing data or start empty. With "Copy my data", the next start copies the database files and `worlds/` to the new location before the backend opens the database, and switches `data_root` only after the copy succeeded; a dialog reports the result. Nothing in the old directory is moved or deleted, nothing in the new one is overwritten (a directory that already holds Covel data is used as it is), and a failed copy is removed while the app keeps using the old directory. Editing `config.toml` by hand and `PUT /api/config/data-root` still copy nothing; the settings page now says where the old data stays. Rules: `docs/reference/desktop-config.md`.
