### Changed

- **A failing dimension provider no longer fails the turn.** When the runtime that publishes `world.dimensions@1` fails, the story still runs and the turn commits and counts. The story reads the saved values frozen when the execution started, the same values the provider republishes, and runtimes that read `world.dimensions@1` as an optional input run without it for the turn. A story that requires `world.dimensions@1` as an input hard-depends on the provider and is refused like a failed story. The provider's failure shows in the turn's run status and can be retried on its own. The `dimension-snapshot-unavailable` skip reason is gone. Rules: [World Model](../en/reference/world-model.md#turn-timing-and-settlement-receipts).
- **A failing `TurnStart` hook of a plugin without a story runtime can cost only that plugin's part of the turn.** When such a handler throws, times out or returns an invalid result, and the execution has a story and some of that plugin's runtimes scheduled, the plugin sits the turn out: its runtimes are skipped with the reason `hook-failed`, its sub-agents refuse calls, and the story and the other plugins run. Its turn-level veto does not apply to that turn, so a hook that must stop the whole turn on its own errors should catch them and return `abort`; a timeout is always handled this way. A plugin made of hooks alone, a hook of the framework or of the story plugin, setup, and a manual run or retry aimed at a runtime that is not a story still stop the turn. A deliberate `abort` works as before, and the failure still counts toward the fault latch. Rules: [Hooks](../en/reference/hooks.md#auxiliary-hook-failures).
- **A failed `PreRuntime` handler skips the runtime it judged with the reason `hook-failed`.** A failed guard hook never lets through what it judged: `PreRuntime` skips the runtime and `PreStateCommit` rejects the proposal, whichever plugin owns it. A story skipped this way, or held back because a runtime it hard-depends on was, is refused instead of committing a turn without a narrative. Rules: [Transactions](../en/reference/transactions.md#backend-implementations).
