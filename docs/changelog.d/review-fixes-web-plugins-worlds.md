### Fixed

- **A session in a world's other language edition now gets that edition's lore.** The session-prep screen sent the world's default-language text as a lore override on every start, so a session created in another content locale still had the default edition in its prompts. The prep editor now shows the edition of the language the session will play in, and an override is sent only when the player changed the text.
- **Scene cast no longer picks characters named inside other words or longer titles.** `scene-stage` read a character as present when any alias appeared as plain text, so "Rin" matched "spring" and "President" matched "Vice President Shiraishi". Cast selection and `npc-graph` retrieval now share `mentionedCharacterIds` from `@covel/plugin-handlers-utils`: names of spaced scripts need word boundaries and a name inside a longer name of another character does not count. Reference: `docs/reference/plugins.md`.
- **Mistport character cards no longer show the secrets the world text keeps from the player.** The character fields and the preset-character cards now carry the same public hints as the world text; the hidden facts moved into each character's narrator-only `persona.secrets`, in both language editions.
- **Installing or updating a world in Settings refreshes the world list.** The home screen and the session-prep screen showed the old list or an old world record until the page was reloaded.
- **A world record invalidated while it was being fetched is read again.** The reader no longer stays on "loading" and the session-prep screen no longer keeps Start disabled.
- **A failed first read of the server's settings is retried.** The settings store now retries three times with growing waits (1, 3 and 9 seconds) instead of only when the window regains focus.
