### Changed

- **The web client and website use plain words in Chinese, English and Russian.** A running game is "game" or "save" (Игра / Сохранение), never "session"; steps replace "runtimes", AI roles replace "slots", and world state replaces "dimensions". The Storyteller, modes and the getting-ready screen use the same names everywhere. The player terms in the glossary list each concept once in all three languages.
- **Russian is complete.** The world-data notices, the model test button and the debugger no longer show English, and the old mix of "сессия", "сеанс" and "игра" is gone.
- **Unused interface strings were removed** from the three web catalogs.
