### Breaking

- **A story agent without an output schema submits story segments.** A schema-less `io.visibility: story` agent used to get a host default of `{narrativeOutput, yield?}`. It now submits the `narrative-engine@2` story shape (`segments`, optional `cues` and `yield`). A submission with only `narrativeOutput` is sent back for repair. Community story agents need no manifest change, only prompts that ask for segments. See [Without an output schema](../reference/plugins.md#default-output-schema).
- **Only an automatically scheduled story runtime provides `narrative-engine@2`.** A manual, event or sub-agent story runtime that writes `io.output.contract` is disabled, and so is a story runtime that names any other output contract. Remove the field. A package has one automatically scheduled story runtime: with several, the one whose runtime ID sorts first plays and the others are disabled (`pnpm validate:plugin` reports them and installation refuses the package). Give the others `trigger.type: manual` or `event`, or move them to their own package.
- **A session admits one story package.** Two packages that both provide `narrative-engine@2` are mutually exclusive without writing `conflicts`. The second one is refused with `single-provider-conflict`. A written `conflicts: [narrative-engine@2]` is ignored. A session that had two story packages active keeps one and nothing has to be recreated: a non-default package replaces the default narrator (Storyteller), and between two non-default packages the one earlier in the session's confirmed plugin order stays. A replacement replaces the default narrator only once it is accepted; if it loses to a conflict or a missing requirement, the default narrator keeps playing.

### Changed

- **The framework owns the story contract.** An automatically scheduled story runtime provides `narrative-engine@2` without declaring `io.output.contract`, root `contracts` or `conflicts`, and a story agent submits its schema without declaring `io.output.schema`. `pnpm validate:plugin` warns when a package still writes these declarations. A declared copy of the schema must match the framework's. A function story runtime gets no default output schema: what its handler returns, a bare `narrativeOutput` included, is still turned into story segments after it returns. The bundled Storyteller and Chat Storyteller drop these declarations and their schema files. See [Framework-owned contracts](../reference/plugins.md#framework-contracts).
- **Presentation and auto-advance read the same story for a turn.** It is the automatically scheduled story runtime's story when it told one; a manual or event-triggered story in the same execution, or a story written by a recursive call, does not displace it. Without it, the execution's one top-level public story counts, whether or not its runtime names a contract. Inline and deferred presentation selectors and auto-advance decide this the same way.
