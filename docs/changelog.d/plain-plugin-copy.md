### Changed

- **Bundled plugins and modes use plain player wording.** Plugin names, settings, panels, buttons and notices drop developer terms (dimensions, pipelines, "DC", type names) and use one name per concept: Storyteller, World state, Bag, Almanac, Story memory, Get ready. Settings that spend AI calls say so, and number settings state their unit. The seven built-in modes are renamed without "Mode" and described in one plain sentence each. See the [glossary](../reference/glossary.md#player-terms).

### Added

- **Russian for all bundled plugins.** Each bundled plugin ships `locales/ru.yaml`, so Russian players see plugin names, settings, panels and notices in Russian instead of English.
