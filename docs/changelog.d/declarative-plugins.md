### Added

- **Declarative community plugins can be enabled without code or runtime approval.** The host verifies prompts, own datasets and declarative UI from current files, including exact browser-only assets. Optional services retain provider authorization, and validated character writes remain available.
- **Plugin rows explain model use before enable.** Automatic, manual, event, setup and delegated runtimes describe their triggers; explicit event calls bypass automatic start-turn, cooldown and run limits. UI-only packages show no model notice. Sandbox session-read consent remains bound to current content, and content or session replacement closes the previous frame's state and stream connection.

### Changed

- **Code upgrades immediately restore ordinary authorization.** No declarative grants are stored; stale proof cannot import modules. Public summaries, including trace discovery, report the current `executionMode`; update development API fixtures together. Obsolete approvals can be retried silently; other approval conflicts remain visible. Sessions and their data require no reset.
- **Generated dataset tools reject extra arguments.** Their execution now matches the advertised strict schema, including rejection of caller-supplied ownership fields.
