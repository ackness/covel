### Changed

- **Plugin code picks instructions by the same rule as prompt bodies.** `pickLocaleText` now chooses with `instructionLocaleFor`, so `COVEL_INSTRUCTION_LOCALE` also switches the instructions that bundled plugins write in code (dice checks, story events, scene cast, memory, NPC relationships, …), and every Simplified Chinese tag such as `zh-Hans-CN` or `zh-SG` reads the Chinese ones. Before, forcing `en` still left Chinese blocks in a Chinese session.
- **A plugin's own prompt templates exist only in English and Simplified Chinese.** `createPromptLoader` from `@covel/plugin-handlers-utils/prompts` reads `<name>.md` and, for a Chinese session, `<name>.zh.md`; other language files are not read and `pnpm check:prompts` reports them. History summaries in a Russian session now get English instructions and are still written in Russian. The framework's own `prompts/` keep their lookup by any locale.
