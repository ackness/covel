### Breaking

- **World facts use one contract ID, `world-ir@2`.** `world-ir-provider@1` (the extraction runtime's output) and `world-ir@1` (the shared fact schema) are replaced by `world-ir@2`, which is both. Bind `from: { contract: world-ir@2 }`, write `schema: contract:world-ir@2` in world data sources, and use `from: "contract:world-ir@2"` in `worldProjections`. A plugin or world pack that still names an old ID finds no provider or schema. Results recorded before the upgrade carry the old ID: retrying an affected consumer on an earlier turn runs it without the facts, and suspended runs of the changed plugins cannot resume. Recreate development sessions that need either, and re-import world data whose sources named `contract:world-ir@1`. Shape: [WorldIR and plugin projections](../en/reference/world-data.md#worldir-and-plugin-projections).

### Changed

- **Story Notes (`world-ir`) is optional for the plugins that read it.** Almanac (`codex`), Relationships (`npc-graph`), Affinity, Quest Log (`core-quest`) and Bag (`inventory`) no longer `require` it, so turning Story Notes off no longer turns them off or adds it back. Without it, Almanac, Relationships and Affinity read the turn's story directly; Quest Log no longer records or advances quests from the story, and Bag no longer adds item changes from the story (changes made with the bag tools or the panel still apply). The Classic Story pack requests Story Notes, Dialogue and Game Master recommend it, and Harukaze Academy requests it, so their default sessions behave as before. Details: [built-in world plugins](../en/builtin/world.md#story-notes-world-ir).
