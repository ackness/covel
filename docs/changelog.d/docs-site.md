### Documentation

- **Covel has a documentation site.** The "Docs" link of the showcase site opens it at `docs/` instead of the repository's `docs/` directory on GitHub. It has a sidebar for each part (guides, reference, internals), full-text search, a table of contents on each page, rendered diagrams, a dark theme and a language switch. Its pages are the Markdown files of `docs/`, built by the new `apps/docs` package (`pnpm --filter @covel/docs dev`).
- **The documentation is rewritten for a reader who meets the product for the first time, in plain Chinese.** The chapters follow that reader: getting started (install, connect a model, first session, packages, backup and upgrade, run from source), what ships with Covel, creating a world, developing a plugin, verifying and shipping, common tasks, reference, and internals. The first-world and first-plugin guides build a real package step by step, and every command they show was run.
- **The documentation has an English edition.** Every page has an English page at the same path under `docs/en/`, served at `docs/en/`. The showcase site's "Docs" link opens the edition of the visitor's language. The Chinese pages are the source.
- **A chapter on what ships with Covel.** `docs/builtin/` describes the gameplay packs, each bundled plugin (what it does in play, what the player sees, its settings, what a world can preset for it) and the app's own features.
- **The changelog is a page of the site** (`docs/releases.md`, which includes `docs/CHANGELOG.md`).
- **The pages moved, and a link to an old path needs the new one.** `docs/guide/` and `docs/architecture/` are gone and `docs/reference/` holds the rewritten reference: `docs/architecture/<name>.md` is `docs/internals/<name>.md`; the guides are under `docs/start/`, `docs/worlds/`, `docs/plugins/`, `docs/ship/`, `docs/recipes/` and `docs/internals/`; `docs/guide/env-registry.md` and `docs/guide/desktop-config.md` are in `docs/reference/`; `docs/glossary.md` is `docs/reference/glossary.md`; the English pages that were `<name>.en.md` are `docs/en/<same path>.md`. `docs/README.md` lists every page. Heading anchors of the reference and internals pages are unchanged. The links in the released sections of `docs/CHANGELOG.md` were repointed the same way.
- **Reference pages were corrected against the code while they were rewritten.** Among others: the HTTP API page shows `nextCursor` as the opaque string it is and no longer lists error codes that do not exist; the SSE page lists seven action types and the real `SseEnvelope`; the tools page lists the dimension proposals; the technical-debt page matches the `ponytail:` markers in source.
