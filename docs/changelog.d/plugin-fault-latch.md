### Added

- **Repeated self-caused auxiliary plugin faults pause the plugin for that session.** Players see a fixed notice and can resume it from the plugin list. Story and dimension providers stay available. A plugin's own failures count, including a failed resume (recorded before the resume route returns an error; buffered writes stay uncommitted and the suspension remains unresolved). A failure caused by a provider plugin, such as a provider exception or an admission failure like a paused provider, keeps its origin and counts against the provider, not the caller; cancellations and cascade failures do not count. Fault counts live only in memory and clear on restart. No development data needs to be recreated.
