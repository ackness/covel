### Fixed

- **Hardened store backends, browser checkpoints, PostgreSQL startup/triggers, and MemoryStore parity.** Browser session checkpoints now strip `embeddingModelId` and `embeddingLockedAt` on export and write so vector indexes re-lock cleanly on hydration; PostgreSQL write-order counters acquire `FOR NO KEY UPDATE` on `sessions` before upserting `session_write_counters` and install triggers idempotently without `ACCESS EXCLUSIVE` `DROP TRIGGER` locks; `createPgStore` closes its pool when bootstrap fails; SQL journal updates/deletes chunk large `IN (...)` lists; SQL grant/instance/setting repositories and `MemoryStore` share identifier, NUL-byte, `undefined -> null`, plain-object `valueFilter`, and rollback snapshot parity; and `isHiddenPluginDataNamespace` rejects bare `"_hidden."`.
- **Fixed media-store concurrency, orphan cleanup, vector backfill locking, and world-data sync atomicity.** PostgreSQL `releaseSession` acquires sorted advisory locks and updates `media_assets` before deleting `media_refs` to match `claimAssets` lock order; SQLite media store serializes DB queries and writes through the connection write gate, cleans up newly published blobs on DB failure, and sweeps aged orphan `.bin` files during cleanup; `POST /api/worlds/:id/sync-data` finalizes media claims inside the session lock and both `sync-data` and `sync-dimensions` schedule memory ingestion after mutations; and `createVectorIngestor` releases `runIngestExclusive` between backfill batches.
- **Hardened world generation, package validation, bulk world-data import performance, and SillyTavern import.** `createWorld` and `writeWorldPackage` require a non-empty manifest `id` and clean up temporary backup directories when replacement renames fail; `validateWorldPackage` targets `worldRoot` directly so dot-prefixed directories work and same-ID siblings never interfere; session world-data import/sync prefetches session characters and lorebook entries once instead of rescanning per row; and SillyTavern imports disambiguate colliding character names/nicknames, preflight converted characters, and skip incomplete PNG covers missing `IHDR`/`IDAT`/`IEND` with a `png-invalid` warning.
