### Security

- **Desktop IPC and navigation checks now enforce frame origin and exclude plugin pages.** Main-frame navigation and privileged IPC channels validate `frame.origin` (rejecting opaque `"null"` origins), exclude `/plugin-assets/` and `/plugin-frame.html`, and deny browser permissions by default (`clipboard-sanitized-write` remains allowed for the trusted app frame). See [security](../en/internals/security.md#desktop-windows).
- **Plugin manifests reject YAML alias bombs and structural locale overwrites.** Frontmatter parsing moved from `gray-matter` to `yaml` v2 (`core` schema, `maxAliasCount: 50`, rejecting unresolved tags and multi-document streams), and localized manifest reconciliation only replaces allowed prose values without overwriting structural subtrees.
- **Non-session webviews no longer read raw session character data or unfiltered RPC responses.** `webview` specs without `bridge: "session"` reject `dataSource.source` (`session.characters`, `session.characterSchema`), enforce surface-scoped handler allowlists, and serialize bridge RPC replies into bounded public outcomes. See [UI panels](../en/reference/ui-panels.md#spec-validation-and-versions).
- **Browser checkpoints, job retries, and approval scopes enforce stricter server boundaries.** Browser checkpoint validation blocks forged `_runtime_jobs` and kernel-reserved `_` namespaces, community plugin activation and `POST /api/sessions/:id/runtime-jobs/:jobId/retry` enforce `plugin.community`, active status, and live approval grants, conflict-evicted plugins rotate their session approval scope, and event/RPC dispatch re-validates subscriber approvals inside the session lock.
- **Outbound HTTP, CORS, origin guard, and world CRUD responses are hardened.** `url-safety` strips trailing FQDN dots before blocklist checks, plugin `fetchWithRetry` caps `Retry-After` delays, `worldAuthoringFlight` is scoped per target instead of globally, `sidecarOrigins` apply only on `self`, `origin-guard` compares full scheme+host and checks `TRUSTED_PROXY_IPS`, and public world responses redact `metadata.storage.path`.

### Fixed

- **Desktop sidecar shutdown and health heartbeat avoid startup races.** Concurrent `before-quit` and failed-startup cleanup share one shutdown sequence per child process, heartbeat IPC checks `!win.isDestroyed()`, and server restarts reset `lastHealthOk`.
- **Saved API key edits immediately propagate to `llm.toml` reloads.** `PUT /api/config/keys` mirrors updated non-external provider keys into `process.env` so `reloadAiStack` resolves `${ENV}` placeholders without a restart.
