### Fixed

- **World update warnings no longer direct players to an unavailable sync control.** Chinese, English and Russian warnings explain that updates preserve data already imported into an existing game and that new starting data requires a new game.

### Documentation

- **World data sync is documented as an API for authors and tools.** The Chinese and English references explain explicit sync, conflict handling and its limits for existing sessions. The player guide directs players to start a new game for new starting data.
