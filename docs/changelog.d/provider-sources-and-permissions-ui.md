### Fixed

- **Plugin provider sources and instance routes now authenticate on desktop.** `plugin-platform` web API calls attach the Electron desktop REST token so `/api/provider-sources`, config flows, app actions, and instance data no longer fail with `401` on desktop builds.
- **Instance settings sections render sign-in controls even before instance data exists.** `InstancePluginPanel` now defaults `alwaysRender` to `true` when no explicit `emptyState` is declared, preventing newly authorized instance plugins from showing the gameplay empty placeholder instead of their sign-in buttons.
- **Per-plugin L3 capability grants now cover all declared capabilities.** Settings → Permissions & security displays and lets players approve or deny every capability a community plugin declares (`plugin.instanceScope`, `plugin.providerSource`, `secrets.own`, `net.authProxy`, `net.loopbackCallback`, `app.scheduler`, `compute.sandboxWorker`, `channel.bridge`, and `net.httpDeclared`), and refreshes platform UI mounts and provider sources immediately after saving. See [plugin installation](../en/reference/plugin-installation.md#permissions-and-the-four-layer-policy).
- **Eliminated duplicate manifest classification diagnostics and bundled plugin noise.** `assessPluginExecution` deduplicates `(file, field)` notices, and the diagnostics summary omits routine code-classification notes for bundled plugins.
- **Surfaced actionable network/proxy errors in plugin config flows, app actions, and GitHub installs.** Outbound transport and TLS failures (`OutboundFetchError`, timeouts, system proxy errors) now return structured `502`/`504` `outbound_network_error` responses instead of opaque `500 Internal server error` pages, and dialogs offer retry, direct proxy settings navigation, and one-click switching to system proxy on desktop.

- **Distinguish unavailable desktop proxy settings from direct routing.** A failed configuration read no longer claims that the system has no proxy; the desktop development shell explains when to test against the packaged app.

### Changed

- **Unified plugin provider sources into the Add Provider dialog and reorganized Permissions & security.** Plugin provider sources now appear directly under a dedicated group in the Add Provider dropdown with actionable permission or sign-in prompts; Settings → Permissions & security is organized into Plugin grants, Policy & sources, and Diagnostics tabs with search, severity/category filters, and collapsible plugin/category grouping.
- **Defaulted desktop outbound proxy mode to `system`.** Fresh desktop `config.toml` files and Electron sidecar boots without an explicit `proxy_mode` now default to `"system"` so OS proxy and PAC rules work out of the box (and connect directly when no OS proxy is configured). See [desktop configuration](../en/reference/desktop-config.md).
- **Redesigned the GitHub plugin and world installer for multi-package repositories.** Added one-click official plugin/world catalog loaders, localized display names and tags, search and directory/kind/selection filters (`plugins/` ahead of `examples/`), already-installed badges, selection chips, and collapsible capability/source details.
- **Reorganized long Settings lists for scanning.** Settings → Install & manage is split into GitHub, Installed (with search and plugin/world filters), and Local tools tabs with compact package rows; provider model lists, the theme library, and AI roles gain search and source/unbound filters once they grow; validation reports, SillyTavern import, and update previews use more compact layouts and bounded reports.
