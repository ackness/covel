### Breaking

- **Encrypted `SecretVault` now uses per-file salted `scrypt` and strictly rejects plaintext downgrade files.** When `COVEL_CREDENTIALS_KEY` is configured, `SecretVault` derives keys with per-file random-salt `scrypt` (AES-256-GCM with strict 12-byte IV and 16-byte tag checks) and refuses to read legacy `SHA-256` or unencrypted (`encrypted: false`) files on disk. Re-save plugin credentials under `<config>/secrets/` if migrating an existing development directory ([env-registry](../en/reference/env-registry.md)).
- **`exec.localBridge` is locked as a reserved capability.** Policy overrides (`PUT /api/permissions/policy` / `COVEL_PERMISSIONS_POLICY`) and persistent plugin grants targeting `exec.localBridge` are now rejected until a local subprocess executor exists ([security](../en/internals/security.md#instance-policy-and-persistent-grants)).

### Fixed

- **Prevented fatal server crash during log file rotation and stream errors.** `server-log-tee` now writes rotation diagnostics through unwrapped `stdout`/`stderr` streams with re-entrancy protection and attaches error handlers to every write stream so disk or permission errors degrade safely without crashing the process.

### Security

- **Enforced capability governance uniformly across every runtime, route, and trust boundary.** Closed `plugin.communityCode: "operator-only"` bypasses on shared hosts, enforced `plugin.declarative` L1–L3 policy across all execution and fork paths, wired live `net.httpDeclared` checks into function and presentation runtimes, and activated real enforcement for `plugin.globalAutoEnable`, `session.bridgeWrite`, and `runtime.highRiskTools` ([security](../en/internals/security.md#instance-policy-and-persistent-grants)).
- **Hardened plugin outbound HTTP, wire isolation, provider sources, sandbox workers, and diagnostics redaction.** `fetchWithAuthProxyRetry` enforces strict direct DNS pinning on fallback, `provider.source@1` validates RFC 9110 headers and invalidates caches on permission changes, media wires enforce plugin ownership matching text wires, `sandbox-worker` strips host `env`/`execArgv` with concurrency and payload caps, and `POST /api/ai/models` / `POST /api/ai/ping` gate diagnostics behind `server.diagnostics`.
- **Hardened rate limiting, request body draining, concealed resume responses, hook matching, and plugin uninstall cleanup.** `X-Forwarded-For` is parsed right-to-left skipping `TRUSTED_PROXY_IPS`, unread body draining streams with O(1) memory bounded to the route's own body limit, `POST /api/sessions/:id/resume` redacts concealed runtimes, `HookPipeline` runs `runsFor` before `match` predicates, and uninstalling a community plugin purges its schedules, flows, provider-source cache, session approvals, secrets, instance data, and persistent grants.
- **Bounded local model relay resources and unblocked graceful shutdown.** Added per-IP channel limits (`4`), body idle timeouts (`60s`), and byte-bounded buffering (`4 MiB` per request / `64 MiB` total), and made relay SSE heartbeats abort-aware ([security](../en/internals/security.md#local-model-relay)).
