### Fixed

- **Dimension-only world sync no longer overwrites non-dimension session records.** `syncWorldDataForSession` iterates only the dimension-filtered write list when `dimensionOnly` is enabled and respects `deferMediaFinalize` before finalizing imported media references.
- **Media cleanup preserves freshly re-claimed assets across all storage backends.** Re-uploading or re-claiming a content-addressed asset refreshes its reference timestamp while keeping the original `pluginId`, and PostgreSQL `MediaStore.cleanup()` runs expired-ref release and asset deletion under the same per-asset advisory lock.
- **SQLite, PostgreSQL, and Memory stores align on JSON string filters and vector operations.** `queryPluginData` `valueFilter` matches strictly top-level JSON string fields across all three backends, `deleteVectors` checks session incarnation consistently before returning when no embedding model is locked, and `searchVectors` breaks equal-distance ties in deterministic byte order.
- **World revisions retain `themeMusic` and UI spec caching recovers from transient failures.** `packages/create` derives `WORLD_MANIFEST_ROOT_KEYS` from `worldManifestSchema`, and `GET /api/ui-specs` evicts rejected cache entries instead of pinning failed promises.
- **Settings store repairs, secret imports, and cross-tab localStorage recovery stay consistent.** Concurrent dynamic registration of a second invalid key during async repair backup no longer bricks the store into read-only mode, `SettingsStore.import()` notifies subscribers for changed secrets, secret `set()` writes schema-normalized values, and `localStorage` unusable-bundle archival acquires the cross-tab settings lock.
- **Web session UI panels, webview state pushes, and data services eliminate stale state and redundant work.** `RightPanel` places the framework/plugin rail divider dynamically when developer view is off, `GameView` avoids stale breakpoint closures and memoizes model-use context, `PluginWebview` skips duplicate `postMessage` full-state pushes when merged state is structurally unchanged, `usePluginThemes` preserves `/api/ui-specs` deduplication, language switches avoid redundant plugin KV refetches, remote `createSessionWorkspace` tracks concurrent runs cleanly without retaining stale rejections, and `LocalDataService` locks `updateSession`, normalizes world comparison JSON, and invalidates cached singletons on browser data reset.
