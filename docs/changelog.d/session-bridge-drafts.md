### Breaking

- **Story streaming events are gone, and session pages must use bridge version 4.** `narrative.delta`, its reset and segment delta payloads, `onDelta` and the loop `stream` / `truncation` options are removed; clients read a story from `output.draft` events while it is written and from complete committed messages afterwards. Session pages (`bridge: session`) read public projection version 4 (`SESSION_BRIDGE_VERSION`): `messages` (committed), `drafts[]` (`{state, text, truncated?}`: unreviewed story text without turn, runtime or plugin identity, following the player's "Show the story as it is written" setting, and leaving `drafts` once the story commits) and `lines[]` (`{kind, text, speaker?, speakerId?}`, the display lines the host stage reads, so a page can build the same line-by-line reader). Pending interactions arrive as public interactions with per-frame answer handles instead of raw pending blocks. Session pages no longer receive panel KV/context/jobs or action/command/event RPC handlers; only individually consented player actions, interaction answers, own manual runtimes, abort and own-panel navigation are available. A page that checks `session.version` must accept 4, and other versions are rejected; update clients and session pages together with the host. Internal provider streams, usage, timeouts and generic structured-content APIs remain, and running, tool and revising progress, Stop and retry stay available. See [story events](../en/reference/protocol.md#narrative-events) and [session projection](../en/reference/ui-panels.md#sessionprojection-version-4).
