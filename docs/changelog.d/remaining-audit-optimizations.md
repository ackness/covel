### Breaking

- **What `ctx.world` returns is frozen.** `ctx.world.characters`, `characterSchema`, `dimensions` and `worldRecord` were a new deep copy on every read: 2.4 ms for a cast of 200, paid again by each step of a loop that looks one character up. A read now returns one frozen copy until the execution buffers another write (the same loop: 494 ms before, under 1 ms after). A plugin that sorted or changed the returned value in place now gets a `TypeError`; copy first (`[...ctx.world.characters]`, `structuredClone`). `docs/reference/plugins.md`.
- **The two unpaged trace endpoints return the newest 5000 events.** `GET /api/traces/:sessionId` and `GET /api/traces/:sessionId/turns` read every trace event of the session into memory, whole prompts included. They now read at most 5000 events, return `nextCursor` when older ones remain, accept `?cursor` to read those, and send `discovery` only on the request without a cursor. A client that needs everything follows the cursor (the debug page's "Load all" and `pnpm e2e:verify` do). `docs/reference/api.md`.
- **`plugin-data.changed` carries `pluginId` and `changes` only.** The `source` field is gone; no client read it. Each change still carries the row's public value, because the client writes it into its own copy and reads nothing back. `docs/reference/protocol.md`.
- **A resolved suspension no longer holds its prompt.** A suspension stored the whole request it continues, and kept it after the resume committed, so a session carried one prompt for every question the player had ever answered, in the database and in every browser checkpoint. `markSuspensionResolved` now keeps the execution identity, locale and turn number and drops the rest. Code that read `pendingContinuation.messages` of a resolved record finds an empty list. Resolved rows written by an earlier version keep their content. `docs/architecture/storage.md`.

### Added

- **`compareText` in the plugin SDK and `@covel/shared`.** Compares two strings by Unicode code point, the order SQLite and PostgreSQL give a binary-collated column. Use it to sort IDs, keys and timestamps and to break ties. `docs/guide/plugin-authoring.md`.
- **The server log names an in-process session lock wait that passes 30 seconds.** The lock used by the Memory and SQLite backends still waits (a turn holds its session for the whole model run, and a request queued behind it must run when it ends), and now writes one line when a wait is that long: the first sign of an owner that never returns.

### Changed

- **Order no longer depends on the server's language.** 66 sorts in the framework and the bundled plugins used `localeCompare` without a locale, so prompt lines, scheduling ties between runtimes, stored rows and API lists could come out in a different order on a machine with another system language. They now compare by code point. Names made of lower-case letters, digits and hyphens keep the order they had; names with upper-case letters, underscores or non-Latin characters can move. The two lists a person reads (model IDs, built-in providers) use a collator with a fixed locale.
- **The event trail is deleted with the traces.** The `events` table holds a copy of every event the bus publishes, the whole value of each changed plugin row included, and nothing deleted it. It now follows `COVEL_TRACE_RETENTION_DAYS` (30 days by default) in the same sweeps as `trace_events`. `docs/architecture/storage.md`.
- **The character roster in the tracker's prompt has a budget.** It listed every character with its whole description on every turn: 22,500 estimated tokens for a cast of 100 with a paragraph each. Within 6000 tokens nothing changes; past that every description is cut to 120 characters, and past that again descriptions are left out (1,300 tokens for the same cast). IDs, names, aliases and types are always listed.
- **A history summary call has an output ceiling.** The call for a summary of N tokens passes `maxOutputTokens` of twice N (at least 1024), so a model that ignores the requested length stops there and not at the slot's whole output budget. A reply cut at the ceiling that already fills its budget is kept and marked `truncated`; a shorter one fails the attempt as before, and the raw messages stay.

### Security

- **`NODE_ENV=test` no longer moves outbound requests off the guarded transport.** With that variable set, provider requests went through the process's global `fetch`, not the npm Undici client that the DNS-pinning and proxy dispatchers belong to. The transport now uses the global `fetch` only where a test run's own setup code has set a mark in the process. `docs/architecture/security.md`.
