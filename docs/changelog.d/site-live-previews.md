### Changed

- **The website now uses editable, localized HTML previews.** Gameplay and world-creation examples follow the page theme and language, with reusable world art, consistent icons, polished Chinese and English storytelling copy, and a pause control. Scenes crossfade on a twelve-second cycle with restrained entrance motion and stable layout.
- **Website languages are selected from a menu.** The theme-aware custom picker supports keyboard selection. The language registry supports additional editions, and selections persist in the URL and local preference.
- **The website opens in dark mode by default.** Manually selected themes and languages are remembered across refreshes and return visits; the saved theme is applied before the first paint.

- **The homepage separates play experiences from shared features.** Its fourth scene now presents Emberback Relay’s survival sandbox; multilingual support has its own feature panel.

### Added

- **Download any supported platform from the website.** macOS and Windows builds are listed together with individual download and copy-link controls, regardless of the visitor's operating system. Windows reserves installer, ZIP and portable formats, recommends the installer, and marks unreleased files without inventing download links.

- **Explore plugins directly on the homepage.** Roll dice, advance a quest, inspect relationships and search the codex in localized, theme-aware browser examples.
- **The homepage foregrounds plugins, world packs and creation.** In-app world generation and workspace Agent Skills have distinct introductions, with small links to the growing plugin/world directories. Downloads are consolidated in one section, reached by sticky quick navigation.

- **The plugin examples now include an interactive relationship graph.** Character profiles and connections are separate from player affinity; optional image generation and speech synthesis extensions are introduced alongside the examples.
- **Authoring skills have a copyable installation command.** The homepage retains direct SKILL.md links, and download formats use a single compact platform catalog.

- **Homepage scenes follow each world’s actual plugin selection.** Three selectable moments show replies, checks, quests, world panels and their sample outcomes, with synchronized plugin highlighting and links to the world configuration.
