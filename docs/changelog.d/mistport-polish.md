### Breaking

- **Mistport 0.4.0 changes its investigation data.** Case Board entries now require sources, contradictions and a secured flag; only the Council records permits and warrants. Eight static setting sections move from dimensions to the lorebook. Reimport or restore the world package and create fresh Mistport development sessions and snapshots; existing session data is not migrated.

### Added

- **Mistport starts with four investigations and eight hidden events.** The quest log tracks Qi's disappearance and three related inquiries. The Case Board records where evidence came from, conflicting accounts, retractions and preservation actions. Narrative rules require independent corroboration and limit flood damage to unsecured evidence within reach of the water; models still judge these rules.

### Changed

- **Mistport's structured Chinese and English prose has been revised.** Character profiles, world rules, dimensions, memory hints and time instructions use clearer language. The opening tide now starts at falling tide, matching the receding water in the opening scene. See the [world data examples](../en/reference/world-data.md#built-in-example-worlds).
