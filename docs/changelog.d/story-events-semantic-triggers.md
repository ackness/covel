### Added

- **Hidden plot events now support semantic condition judging, hidden options, and hidden rewards.** `story-events` extends `contract:story.events@1` additively with natural-language `judge` conditions (and string shorthand), `affinity` / `item` / `attribute` / `selected` deterministic leaves, unlockable `options[]`, and `rewards[]` (`item`, `lorebook`, `narrative`). A concealed `audit` evaluator (`story-events/assess`) and read-only sub-agent (`story-events/judge`) short-circuit deterministic gates, batch shortlisted semantic checks under `semanticJudge` / `maxJudgedPerTurn` without delaying first-token narration, and never expose hidden payloads, options, or rewards until unlocked or selected. Unlocked options appear below the story in Read/Chat mode and merge into `stage.choices@1` in Stage mode. Both `mistport` and `haruka-academy` include a hybrid hidden option + reward example. See [RPG Mechanics](../en/builtin/rpg.md#hidden-plot-events-story-events) and [World Data](../en/reference/world-data.md#hidden-data-visibility-hidden).
- **In-app AI world creation and revision can now author hidden plugin sources.** Plugin manifests allow `authoring.generate` (`offer` / `default`) on hidden non-media sources keyed by `id`, `story-events` declares `authoring.generate: offer` with a localized summary, and generated packages, portable `contractData`, and fallback descriptors all preserve `visibility: "hidden"` without projecting to the lorebook. World translation also preserves condition identifiers (`dimension`, `attribute`, `revealed`, `selected`, `timing`, `scope`) while translating `watch.keywords`. See [Advanced Plugin Guide](../en/plugins/advanced.md).

### Fixed

- **Portable world contract data preserves `visibility: hidden`.** World packages imported through `metadata.contractData` now inherit `visibility: hidden` from plugin authoring conventions (or honor explicit `visibility: "hidden"`) and reject combining hidden visibility with `lorebook: true`.
