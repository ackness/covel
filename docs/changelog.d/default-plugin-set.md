### Added

- **A "Narrative Only" gameplay pack.** It turns on the narrator and World Dimensions and turns the other always-on plugins off: no opening form, character creation, world time, Story Memory or history compaction. It starts every bundled world.
- **Gameplay packs can turn plugins off.** A pack's `excluded` lists plugins, `kind: core` ones included, that choosing the pack turns off; the player can turn them back on, and the next pack lifts only the exclusions this one added. Reference: `docs/reference/world-data.md`.
- **"Back to the minimal set" on the session prep screen.** One click keeps only the narrative plugins, the plugin that holds the world's dimensions and what the world requires, and turns everything else off.
