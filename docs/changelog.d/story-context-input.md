### Added

- **Plugins can hand this turn's notes to the story without binding a narrator.** A `pre-turn` runtime declares `io.storyContext` (`select`, `priority`, `order`) to point at a value in its own output: text, `{ title, content }`, or `null` for nothing to say. A reader, usually the narrator, writes `from: { kernel: story-context@1 }` and gets every note of the turn, ranked by priority, deduplicated and fitted into `min(3000, 10% of the story input window)` tokens; notes that do not fit are left out whole and listed as omitted. Agents read a `<story-context>` block in their turn context; functions read `ctx.inputs`. An invalid note is left out without failing its provider, and the reader's trace records a `story-context.selected` event that names a concealed provider by its package display name only. The SDK exports `STORY_CONTEXT_INPUT`, the `StoryContext*` types and `storyContextContributionSchema`; `@covel/plugin-test-utils` adds `storyContextSlot`. See [the kernel input `story-context@1`](../reference/plugins.md#story-context) and [add a note for the story](../en/plugins/advanced.md#feeding-the-story).
