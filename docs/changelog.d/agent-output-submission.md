### Added

- **Final output has a dedicated review hook.** `ReviewAgentOutput` checks validated submissions using public results of the subject runtime’s own tools. It can request correction, without replacing accepted output or creating effects. `PostLLMResponse` continues to inspect actual provider responses. See [hooks](../en/reference/hooks.md#reviewagentoutput).
- **Complete stories can opt into segment reveal.** The shared `Reveal` component and template metadata reveal whole blocks within two seconds, with Show all and a device-local Instant text override. Reduced motion, history, reconnect, reload and view remount are instant. Semantic content and copy/export remain complete. See [Reveal](../en/reference/ui-components.md#complete-content-reveal).

- **Loop profiles expose bounded correction and finalization policy.** `story`, `actor` and `system` share submission validation. Story and actor profiles can request submission when a tool loop repeats; system fails. Steering remains independent of provider streaming. Deadline reserve defaults to zero, and enabled finalization offers one submission-only request after required work. See [loop profiles](../en/reference/plugins.md#loop-profile-agentloopprofile).

### Changed

- **Breaking: every agent ends through `submit-output`.** Remove `finishWith`, `completion.require: explicit` and `runtime-done`; business `completion.afterTools` prerequisites no longer terminate a runtime. Loaded object schemas remain unchanged, with host defaults for schema-less story and system agents. Reply text and the last business result cannot complete an agent. Rejections return correlated tool errors and use ordinary steps: output repair defaults to one correction, review to two, and missing business work to one. Finalizers offer only submission; no tools-off repair or lenient invalid-story acceptance remains. See [completion](../en/reference/plugins.md#agent-output-submission) and [submission](../en/reference/tools.md#submit-output).
- **Acceptance still precedes persistence.** Output never creates effects merely because it arrives through a tool. Commit receipts and persisted messages determine success; failed commit, cancellation, refusal and rejected candidates publish no story. Resubmission keeps previous business work without repeating writes. Resumes retain the admitted schema, spent steps and correction counters; children use the same gate while keeping their existing privacy and write boundaries. See [flow](../en/internals/flow.md) and [resume](../en/reference/protocol.md#suspend-and-resume).
- **Breaking: player story streaming and session bridge version 2 are removed.** Remove `narrative.delta`, reset/segment delta payloads, `onDelta`, loop `stream`/`truncation`, `session.streaming` and bridge append messages. Update clients and session pages together to bridge version 3 and complete committed messages. Internal provider streams, usage, timeouts and generic structured-content APIs remain available. Running/tool/revising progress, Stop and retry controls remain accessible without candidate or reviewer text. See [story events](../en/reference/protocol.md#narrative-events) and [session projection](../en/reference/ui-panels.md#sessionprojection-version-3).
- **Stage input no longer waits for reading.** Character typing and the final-click gate are removed. Paragraph navigation, rereading and local Auto-play remain independent of action availability and server advancement. Scene Stage opts into the shared segment presentation; instant remains the host default.
- **Upgrade affected author packages and active continuations together.** Update agent prompts, `ReviewAgentOutput` registrations, fixtures and HTML session pages; reload declarations and cached compiled definitions. Recreate active agent suspensions and checkpoints containing their continuations, and re-record affected exact-match captures starting with Lantern Barrow. Business contract IDs and compatible committed story history remain valid; no blanket database deletion is required. See [testing](../en/plugins/testing.md) and [recording](../en/ship/real-model.md#recording-and-replay).
