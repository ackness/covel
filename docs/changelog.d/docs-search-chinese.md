### Documentation

- **Search in the Chinese documentation finds a word in the middle of a phrase.** The search box split Chinese text only at punctuation, so a query matched the start of a clause or nothing: the Chinese for "preset quests" did not find the page about them. Chinese text is now indexed from every character on, in pieces of up to four characters. The Chinese search index is larger for it (about 2.1 MB compressed, from 0.9 MB); it is loaded when the search box is first opened.
