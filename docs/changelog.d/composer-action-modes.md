### Added

- **The composer offers the action kinds the player's seat may submit.** A mode is a kind from the session's action-kind catalogue (`say`, `act`, a host seat's `narrate`, `direct` and `advance`, and plugin kinds), named by the kind's `display` label, icon and placeholder. A kind with a `schema` shows its fields under the input (flat strings, numbers and booleans); a schema the composer cannot draw hides that mode and `pnpm validate:plugin` warns. The stage's free input uses the same modes. Steering stays text only, so other modes wait for the turn to end. See `docs/reference/ui-panels.md`.
- **A seat that plays several characters gets a current-character selector.** It appears above the composer and the stage free input when the selected mode is taken as a character, switches the seat's current character through the seats API, and is off while a turn executes. See `docs/reference/world-model.md`.
- **Player messages say who acted and how.** A message that recorded its actions shows "character · kind" instead of "Player" unless it is a plain `say` by the only character the seat binds. Both `GET /api/sessions/:id/messages` and `GET /api/sessions/:id/view` return `actions` on player messages. See `docs/reference/api.md`.
