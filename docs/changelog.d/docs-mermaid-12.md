### Documentation

- **Documentation diagrams use Mermaid 12.** The documentation site now requires an ES2024 browser (Safari 17.4+) and keeps the existing flat shapes, layout and label widths. This browser requirement applies only to the documentation site.
- **Multiple diagrams on a documentation page render reliably.** Each diagram now has its own SVG ID, so diagrams drawn together or after a theme change cannot overwrite one another.
