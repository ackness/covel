### Fixed

- **A game goes on when the plugin that keeps its dimensions is gone.** When the plugin a session's dimensions belong to was uninstalled, failed to load or lost a dependency, every turn stopped, the session view failed, and the player could not turn any plugin on or off. Now the story goes on with the dimensions as they were saved, nothing changes them, and the game screen says they are paused until that plugin is back. Other plugins can be turned on and off meanwhile. Rules: `docs/reference/world-model.md`.
- **Several plugins that keep world dimensions are explained, not a server error.** Starting a game with more than one of them failed with "Conflicting dimension providers". Preflight and session creation now answer `409 dimension_provider_conflict` with the plugins in `details.candidates`, and the prep screen asks the player to keep one of them. Turning on a second one during a game is refused with the same code, and a turn that meets several names them and says what to turn off. Codes: `docs/reference/api.md`.
