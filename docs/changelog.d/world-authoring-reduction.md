### Breaking

- **File worlds author dimensions only in `data/dimensions.yaml`, and generated results use `packageContent.dimensions`.** Locale overlays stay beside it. Descriptors may change or disable that source but cannot add another dimension table. Strict validation rejects `world.yaml.dimensions`; tolerant loading diagnoses and omits it without conversion. Generated and revised portable results use `packageContent.dimensions`, and file export, server-store and browser-local records preserve the same validated definitions. Reauthor the canonical file or regenerate, reimport and start new sessions; recreate old inline generated creation and revision payloads, persisted drafts and browser copies, inline-authored external fixtures, and affected development sessions, branches, snapshots and recordings. Resolved records require no database schema change or automatic migration.
- **Development session selections now freeze inferred data requirements.** Recreate sessions and recordings that assumed the previous receiver set and reimport modified world copies. Database structures and existing player rows are unchanged.
- **Worlds select gameplay through one ordered `plugins` field, and `pluginPolicy` is removed.** The authored `pluginPolicy` field and its `preset`, `plus`, `packs` and `requires` fields are replaced by an ordered `plugins` list: prefixed pack, plugin and contract references share one interpretation across validation, preparation and collections. The first pack selects the initial mode, alternatives remain available, independent requests survive pack changes, and manual exclusions win; missing optional features produce notices and play can start. Presentation overrides move to `pluginPitch`, and the plugin-plan API returns `selection` and bounded diagnostics. Recreate development worlds and sessions.

### Added

- **World content selects its data receivers automatically.** Enabled files, character extensions and portable records request accepted data contracts independently of gameplay capabilities. A unique eligible receiver joins automatically; ambiguity, exclusions and approval remain player choices. Unknown structured files receive an actionable author warning.
- **Players see safe explanations for omitted world data.** Public sources retain their safe declaration titles while hidden identities and errors stay private. Distinct source omissions remain separate. Unreceived or colliding conventional sources and character fields preserve managed records, ledgers and media during sync. Receivers with unavailable direct or transitive dependencies stay deferred under the same admission rules as preflight.
- **World introductions default to public name, summary and tags.** Optional `pluginPitch` fields override each value independently, with locale resolution at display time. Revisions preserve edits and removals, resolving translated pitch to the world's content language before writing authored YAML. Derived text never reads private lore and is never saved as authored data.

### Changed

- **Browser dimension edits keep the canonical record and its projection synchronized.** Edited initial values and explicit clears survive checkpoint upload, server hydration and session initialization without an older metadata copy restoring the previous definitions. Empty edits clear definitions, package reload preserves player edits until explicit restore, and public revision replacements are isolated from narrator-only lore.
- **Pending data-receiver approvals stay separate from explicit plugin requests.** Inferring a receiver does not submit it as a player selection; world and player requests retain their existing approval flow.
- **Live plugin changes preserve world provider choices.** Unrelated switches do not add new core defaults or replace an unavailable world provider. Presentation packages require a gameplay or player selection; seed assets alone do not enable them.
