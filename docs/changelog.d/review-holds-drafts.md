### Added

- **A hook can keep story drafts from players until it has accepted them.** A `contributes.hooks` entry `{ event, holdsDrafts: true }` on `ReviewAgentOutput`, `PostLLMResponse`, `PreToolUse` or `PostRuntime` makes the stories of every session that enables the plugin appear only once the hook has accepted them: for the first three, after every review accepted the submission, so a rejected version, such as one that names a mystery's culprit early, is never shown, and the story still appears before later plugins run and the turn commits; for `PostRuntime`, only after the commit, since `replace.result` can still replace an accepted story. A community hook the player has not approved does not run and does not hold drafts. The declaration grants no permission and `pnpm plugin:extract` keeps it. See [holding story drafts](../en/reference/hooks.md#holds-drafts).
