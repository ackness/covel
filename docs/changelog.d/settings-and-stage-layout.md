### Added

- **Resize the story and dialogue panels.** When Read uses a scene backdrop, dragging the edge resizes the text, suggestions and input together. Stage mode has its own handle on the response panel. Both support the keyboard and remember their widths separately.
- **Get local model setup help at the API endpoint.** Hosted trials show connection steps for Magpie, Ollama and LM Studio, with a shortcut to copy the current site's origin.
- **Browse the restored design showcase.** Open `/design-system.html` to preview the built-in themes in Simplified Chinese, English or Russian. Settings, reading and Debug share layout rules with the showcase.

### Changed

- **Settings uses clearer sections and fits narrow screens.** Provider connections and model configurations have their own tabs, advanced explanations can be expanded, and detailed forms have more space on wide screens.
- **Clarify file actions and narration preferences.** Settings use file import and export icons. Each storyteller explains where its perspective setting applies.
- **Update the built-in DeepSeek model to `deepseek-flash`.** The provider settings show the official endpoint when it is the active built-in connection.
- **More room for dialogs.** Conversation history, expanded plugin panels, the settings media preview and game settings use more of a wide screen. The game menu scrolls in short windows.
- **Easier to follow speakers and choose an action.** Speaker names and portraits have more room in Read. Action suggestions and the input controls have clearer spacing.
- **Consistent debugger layouts.** Trace, save data, cost and plugin views share the available width. Long identifiers and cost breakdowns wrap on smaller screens.

### Fixed

- **Last Train Out character names.** The Chinese world introduction uses the same names as the Chinese character records.
