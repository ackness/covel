### Changed

- **On the native Gemini protocol, the turn's data and rules no longer break the prompt cache at the start of every request.** `google-generative-ai-v1` used to put every system message into `systemInstruction`, which precedes the conversation, so the per-turn text changed the very beginning of the request. Now only the system messages ahead of the conversation go there; a later one stays in place as user text in `<system-instruction>` tags, as the Anthropic protocol already does, so the request is identical up to the end of the previous turn's history. Neighbouring turns of one role are merged into one, and function responses always directly follow their function call. This is the default; `lateSystemAsUser = false` in the slot's `providerOptions` restores the earlier shape (every system message in `systemInstruction`) and is the way back if Google's endpoint refuses a request. The model now reads that text as user text instead of a system instruction; quality was not compared. The request shape was accepted across a tool loop by a local proxy that imitates the Gemini interface; it was not verified against Google's endpoint, and cache reads on Gemini were not measured. See `docs/reference/prompt-structure.md` and `docs/reference/slots.md`.
