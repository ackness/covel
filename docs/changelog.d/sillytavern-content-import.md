### Added

- **Import SillyTavern character cards and lorebooks as a world.** Settings → Install & manage offers a data-only preview and import for V1/V2/V3 JSON cards, PNG cards and world-info JSON, with conversion reports, content cleaning and a metadata-free PNG cover. Extensions, scripts and executable macros are never run. Creator notes stay out of model prompts and are reported, lorebook-only worlds use a neutral premise without copying disabled or selective entries into world text, and the first PNG supplies the cover while each later image is reported as omitted.
