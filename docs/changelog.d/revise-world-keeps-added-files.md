### Fixed

- **"Revise this world" no longer destroys files a person added to an AI-generated world.** `.covel-generated.json` now lists every file the app wrote into the package with a hash of its content. When the package holds a file that is not in the list, or a listed file whose content was edited, `POST /api/ai/revise-world` returns `409 world_package_modified` with the files in `details.added` / `details.changed`, the world page names them, and the package is left as it is. The check runs before the model is called and again just before the package is replaced. Translations made in the app are recorded in the list, so a translated world can still be revised. Rules: `docs/reference/api.md` (revise-world) and `docs/reference/world-data.md`.

### Upgrade notes

- **A world generated by an earlier build can no longer be revised in the app.** Its `.covel-generated.json` has no file list, so nothing says which files the generator wrote; after a restart the world loads without `metadata.generated` and "Revise this world" is not offered (`409 world_not_revisable` from the endpoint). Generate the world again to get a revisable one, or keep the package and edit its files. There is no migration.
