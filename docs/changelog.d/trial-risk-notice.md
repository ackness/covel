### Changed

- **The public trial's notice is a warning that stays reachable.** The card now reminds players to use a temporary API key and that saves live only in their browser, since a trial cannot export a full save and "Export save" writes the chat log only. Closing it collapses it into the notification bell instead of hiding it for good, and later visits keep it there; a notice dismissed by an earlier version opens once more. See [hosted trial](../start/hosted-trial.md).
