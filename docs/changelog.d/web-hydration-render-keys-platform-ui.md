### Fixed

- **Browser-private hydration and execution recovery no longer stall indefinitely.** Failed workspace hydration now clears the hydrating state and reports a stalled error with retry controls, recovery polling stops after consecutive network failures instead of looping forever, stale pending browser commits clear on `409 browser_checkpoint_required`, and world mutations await initial catalog hydration before acquiring world locks.
- **High-frequency turn streaming no longer triggers full sidebar and plugin panel re-renders.** Structural session state now flows through a dedicated context so token drafts and step ticks do not re-render plugin panels, right-panel state, or permissions views; switching panels resets cached panel state stores, and crossfaded stage backdrops unmount replaced layers once transitions finish.
- **Model relay lifecycle and provider key headers follow active endpoints and bindings.** Removing local endpoints or disabling relay support now closes the relay SSE stream and aborts in-flight local fetches, `404` unsupported latches reset on provider or health updates, `provider.source@1` profiles no longer strip manual vendor API keys, and targeted `/api/ai/ping`, `/api/ai/models`, and `/api/ai/protocols` probes send only explicitly resolved provider keys.
- **Platform config flows, status badges, floating windows, permissions, and settings persistence handle edge cases cleanly.** Config flow polling preserves typed inputs on unchanged steps, scrubs secret inputs on step transitions and close, validates finite numeric inputs, and cancels active runs on unmount; status badges poll without overlapping requests; floating windows keep state across minimize/restore, stop drags on `pointercancel`, and close session windows when switching sessions; Permissions groups active session grants per plugin and preserves Danger Zone confirmation when a save fails; SettingsStore rejects server-scoped keys in batch/replace/import writes and reports per-channel notifications accurately on partial `clearAll` failures.

### Security

- **Plugin webview `src` URLs fail closed outside `/plugin-assets/`.** Sandboxed plugin webviews now reject non-`/plugin-assets/` paths, protocol-relative URLs, path traversal segments, and control characters before probing or opening a bridge connection.
