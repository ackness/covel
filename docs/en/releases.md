# Changelog

What changed in each version: what was added, changed and fixed, and what to check before you upgrade. Before an upgrade, read the "Upgrade notes" and "Breaking" entries of the version, then make a backup as [Data, backup and upgrade](./start/data-and-upgrade.md) describes.

Entries for the next release are kept in [`docs/changelog.d/`](https://github.com/ackness/covel/tree/main/docs/changelog.d) of the repository until it is published.
