# 内置插件与功能

Covel 装好之后就带着一组插件和四个世界。这一章告诉你它们各自是什么、在游戏里会看到什么、可以调什么。要查面板来自哪个插件、某项功能能否关闭，可以从这里开始。

内置的插件和世界只是示范，不是必须用的。

## 玩法包：一次选好一组插件

开一局游戏时，你不需要一个个挑插件。**玩法包**是搭配好的一组插件，在准备页选一个就行。内置四个：

| 玩法包                           | 适合               | 带上的插件                                                 |
| -------------------------------- | ------------------ | ---------------------------------------------------------- |
| 传统故事模式 `traditional-story` | 长篇探索，读故事   | 叙事、行动建议、设定图鉴、关系图谱、世界规则               |
| 对话模式 `dialogue-mode`         | 角色对话、视觉小说 | 对话叙事、场景舞台、行动建议、角色资料、世界规则、回复变体 |
| 低成本 `low-cost`                | 想少花模型费用     | 叙事、世界规则                                             |
| 只要叙事 `narrative-only`        | 只想读故事，最省钱 | 叙事                                                       |

前三个玩法包都带上开局准备、世界维度和角色创建，并推荐启用故事记忆。“只要叙事”关掉了其余默认启用的插件：没有开局表单、角色创建和世界维度，也没有世界时间、故事记忆和历史压缩。世界声明的维度不会导入，会话照常开始。

准备页的“回到最小集合”按钮也能一键回到这样的组合：只留叙事插件，以及它们和世界必需的插件。

世界可以在内置玩法包上加选插件，并给这套组合起一个名字。例如“提灯古冢”的“经典跑团”在传统故事的基础上加了跑团规则、骰子判定、任务日志、行囊和好感度；它不是另一个可全局选择的玩法包。选了玩法包之后，你仍然可以在准备页的“自定义插件与高级设置”里增减插件。

## 全部内置插件

带“默认启用”标记的插件会自动加入每一局，你可以在准备页把它们关掉。有的插件依赖其他插件提供的能力；缺少提供者时，依赖它的插件会停用，界面会说明缺少什么，其余功能继续运行。其余的由玩法包、世界或你自己选择。

### 叙事与记忆

| 插件                                        | 做什么                                           | 默认启用 |
| ------------------------------------------- | ------------------------------------------------ | -------- |
| [叙事](./story.md) `narrator`               | 写每个回合的故事正文                             | 是       |
| [对话叙事](./story.md) `chat-mode-narrator` | 用角色对话的方式讲故事，可单独使用，场景舞台可选 |          |
| [行动建议](./story.md) `guide`              | 在正文后面给出几个可以点的行动                   |          |
| [回复变体](./story.md) `branch-reply`       | 对同一回合换一种写法                             |          |
| [故事记忆](./story.md) `memory`             | 记住进行中的剧情、当前场景和主角状态             | 是       |
| [历史压缩](./story.md) `history-compaction` | 对话太长时把早先的部分压缩成摘要                 | 是       |

一局可以有多个玩家角色。两个叙事插件跟随你当前扮演的角色（见[叙事 · 你扮演的角色](./story.md#你扮演的角色)和[座位](../reference/world-model.md#座位)）。其他还按“玩家角色”工作的内置插件（故事记忆、行囊、骰子判定、跑团规则、角色创建、场景舞台、角色资料）在有多个玩家角色时按第一个处理。

### RPG 玩法

| 插件                                  | 做什么                                               | 默认启用 |
| ------------------------------------- | ---------------------------------------------------- | -------- |
| [骰子判定](./rpg.md) `dice-check`     | 预掷骰子决定风险行动成败，无可用能力时不显示属性标签 |          |
| [跑团规则](./rpg.md) `tabletop-rules` | 开局分配属性点，玩家主动发起属性检定                 |          |
| [任务日志](./rpg.md) `core-quest`     | 记录任务和目标，状态徽标跟随界面语言                 |          |
| [行囊](./rpg.md) `inventory`          | 记录主角带着什么，可以直接使用和丢弃                 |          |
| [好感度](./rpg.md) `affinity`         | 记录玩家与 NPC 的数值好感，并供叙事读取当前分数      |          |
| [隐藏事件](./rpg.md) `story-events`   | 满足条件才出现的剧情                                 |          |

### 角色与世界

人物、世界事实和维度更新会保留叙事段落的说话者/行动者信息；玩家消息是独立来源，详见[角色与世界](./world.md)。

| 插件                                         | 做什么                                       | 默认启用 |
| -------------------------------------------- | -------------------------------------------- | -------- |
| [开局准备](./world.md) `pregame`             | 开局时收集玩家的选择                         | 是       |
| [角色创建](./world.md) `char-creator`        | 按表单答案创建主角，并更新人物状态           | 是       |
| [角色资料](./world.md) `character-blueprint` | 世界预置的角色设定和立绘                     |          |
| [世界维度](./world.md) `world-init`          | 准备角色属性与维度，并更新维度状态           | 是       |
| [世界时间](./world.md) `world-time`          | 时间流逝、日夜与规则摘要                     | 是       |
| [世界规则](./world.md) `living-world-rules`  | 把世界规则带进每个回合，类别徽标跟随界面语言 |          |
| [设定图鉴](./world.md) `codex`               | 记录人、地、物，类别徽标跟随界面语言         |          |
| [关系图谱](./world.md) `npc-graph`           | 记录人物、团体和势力的关系图                 |          |
| [世界事实提取](./world.md) `world-ir`        | 整理本轮事实并逐项检查任务目标，供其他插件用 |          |

### 舞台与声音

## 四个内置世界

雾港、遥风学园和提灯古冢各示范一种玩法：雾港是传统叙事，遥风学园是舞台模式，提灯古冢是跑团规则。Emberback 用英文写成，示范一个世界怎样提供多种语言版本。

| 世界                                | 玩法                   | 值得看的地方                                       |
| ----------------------------------- | ---------------------- | -------------------------------------------------- |
| 雾港・裂潮纪 `mistport`             | 传统叙事的黑暗奇幻调查 | 隐藏剧情、调查用的记忆、立绘                       |
| 遥风学园 `haruka-academy`           | 舞台模式的校园群像     | 对话叙事、日夜场景图、透明立绘、校园作息计时       |
| Emberback Relay `emberback`         | 科幻边境悬疑，英文写成 | 示范一个世界怎样带多种语言（英文为主，另有中文版） |
| 提灯古冢・初次远征 `lantern-barrow` | 经典跑团地城探索       | 开局配点、掷骰检定、地城面板                       |

想照着它们做自己的世界，文件都在仓库的 [`worlds/`](../../worlds) 目录里。
