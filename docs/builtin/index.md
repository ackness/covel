# 内置插件与功能

Covel 装好之后就带着一组内置插件和四个世界。这一章告诉你它们各自是什么、在游戏里会看到什么、可以调什么。要查面板来自哪个插件、某项功能能否关闭，可以从这里开始。

内置插件和世界只是示范，不是必须用的；社区世界与内置世界使用同一套 `plugins` 前缀引用。

## 玩法包：一次选好一组插件

开一局游戏时，你不需要一个个挑插件。**玩法包**是搭配好的一组插件，在开局准备页选一个就行。内置七个：

| 玩法包                       | 适合               | 带上的插件                                                         |
| ---------------------------- | ------------------ | ------------------------------------------------------------------ |
| 经典故事 `traditional-story` | 长篇探索，读故事   | 讲述者、行动建议、图鉴、人物关系、世界规则                         |
| 对话 `dialogue-mode`         | 角色对话、视觉小说 | 聊天式讲述、舞台画面、行动建议、角色资料、世界规则、备选回复       |
| 省钱 `low-cost`              | 想少花模型费用     | 讲述者、世界规则                                                   |
| 纯故事 `narrative-only`      | 只想读故事，最省钱 | 讲述者                                                             |
| 主持人 `dm-mode`             | 主持人口吻         | 开局准备、世界状态、讲述者、主持人面板；关闭建角                   |
| 群像对话 `ensemble-dialogue` | 多个角色共同演出   | 开局准备、世界状态、建角、聊天式讲述、角色扮演、轮流发言、舞台画面 |
| 旁观 `spectator`             | 观察 NPC 推进      | 同群像组合，包含主持人面板，但不创建玩家角色                       |

前三个玩法包都带上开局准备、世界状态和角色创建，并推荐启用故事记忆。“纯故事”关掉了其余默认启用的插件：没有开局表单、角色创建和世界状态，也没有世界时间、故事记忆和长篇故事记忆；世界声明的维度不会导入，游戏照常开始。

开局准备页的“回到最小集合”按钮也能一键回到这样的组合：只留叙事插件，以及它们和世界必需的插件。

世界可以在内置玩法包上用 `plugins`（含 `pack:`、`plugin:`、`contract:`）加选能力，并通过 `data/` 目录里的约定文件自动启用对应的通用插件（例如任务日志、背包、好感度或开局配点），再给整套开局组合起一个名字。例如“提灯古冢”在“经典故事”的基础上显式请求 `dice-check` 与 `action-check@1`，并凭约定文件自动带入属性判定、任务日志、背包和好感度，把这套组合称为“经典跑团”；它不是另一个可全局选择的玩法包。选了玩法包之后，你仍然可以在开局准备页的“自定义插件与高级设置”里增减插件。

## 全部内置插件

“主持人”与“旁观”玩法请求“主持人面板”，“群像对话”仅推荐；它不改变默认视图、身份或策略。图鉴和人物关系只提供右侧面板，可用“放大面板”查看更大视图；面板本身不调用模型，故事行动仍按所选模型分工计费。

带“默认启用”标记的插件会自动加入每一局，你可以在开局准备页把它们关掉。有的插件依赖其他插件提供的能力；缺少提供者时，依赖它的插件会停用，界面会说明缺少什么，其余功能继续运行。其余的由玩法包、世界或你自己选择。

### 叙事与记忆

| 插件                                                       | 做什么                                           | 默认启用 |
| ---------------------------------------------------------- | ------------------------------------------------ | -------- |
| [叙事](./story.md) `narrator`                              | 写每个回合的故事正文                             | 是       |
| [聊天式讲述](./story.md) `chat-mode-narrator`              | 用角色对话的方式讲故事，可单独使用，舞台画面可选 |          |
| [角色扮演](./story.md) `character-agent`                   | 只扮演所选角色并返回公开台词/动作                |          |
| [轮流发言](./story.md) `turn-policy`                       | 一个服务，通过自身设置选择五种策略               |          |
| [主持人面板](./story.md#主持人面板dm-console) `dm-console` | 公开在场角色、交互、故事与当前身份输入           |          |
| [行动建议](./story.md) `guide`                             | 在正文后面给出几个可以点的行动                   |          |
| [备选回复](./story.md) `branch-reply`                      | 对同一回合换一种写法                             |          |
| [故事记忆](./story.md) `memory`                            | 记住剧情与人物状态，世界可追加记忆块             | 是       |
| [长篇故事记忆](./story.md) `history-compaction`            | 对话太长时把早先的部分压缩成摘要                 | 是       |

一局可以有多个玩家角色。两个叙事插件跟随你当前扮演的角色（见[叙事 · 你扮演的角色](./story.md#你扮演的角色)和[座位](../reference/world-model.md#座位)）。故事记忆、背包、骰子判定、属性判定、角色创建和角色资料跟随行动角色，没有行动角色时取主座位的当前角色；舞台画面仍按第一个玩家角色处理。

### RPG 玩法

[背包](./rpg.md#背包inventory)会核对工具已处理的变化和骰子判定已扣除的物品，避免重复记账。

| 插件                                  | 做什么                                                                   | 默认启用 |
| ------------------------------------- | ------------------------------------------------------------------------ | -------- |
| [骰子判定](./rpg.md) `dice-check`     | 预掷骰子决定风险行动成败；随身物品加修正，失败按世界数据丢物品或推进时钟 |          |
| [属性判定](./rpg.md) `tabletop-rules` | 开局分配属性点，玩家主动发起属性检定                                     |          |
| [任务日志](./rpg.md) `core-quest`     | 记录任务和目标；期限过了的任务或目标自动判为失败                         |          |
| [背包](./rpg.md) `inventory`          | 查询背包、结算交易，记录物品得失和装备；物品可以帮某类检定               |          |
| [好感度](./rpg.md) `affinity`         | 记录玩家与 NPC 的数值好感，供叙事读取；关系差的 NPC 不愿配合检定         |          |
| [隐藏剧情](./rpg.md) `story-events`   | 满足确定性或语义条件才解锁的隐藏剧情、隐藏选项与隐藏奖励                 |          |

背包与好感度的世界预置记录接受数据集校验；同步允许移除权威来源已删除的预置记录。

### 角色与世界

人物、世界事实和维度更新会保留叙事段落的说话者/行动者信息；玩家消息是独立来源，详见[角色与世界](./world.md)。

| 插件                                         | 做什么                                       | 默认启用 |
| -------------------------------------------- | -------------------------------------------- | -------- |
| [开局准备](./world.md) `pregame`             | 开局时收集玩家的选择                         | 是       |
| [角色创建](./world.md) `char-creator`        | 按表单答案创建主角，并更新人物状态           | 是       |
| [角色资料](./world.md) `character-blueprint` | 世界预置的角色设定和立绘                     |          |
| [世界状态](./world.md) `world-init`          | 准备角色属性与维度，并更新维度状态           | 是       |
| [世界时间](./world.md) `world-time`          | 时间流逝、日夜与规则摘要                     | 是       |
| [世界规则](./world.md) `living-world-rules`  | 把世界规则带进每个回合，类别徽标跟随界面语言 |          |
| [图鉴](./world.md) `codex`                   | 记录人、地、物，类别徽标跟随界面语言         |          |
| [人物关系](./world.md) `npc-graph`           | 按本名与别名维护人物、团体和势力关系         |          |
| [故事整理](./world.md) `world-ir`            | 整理本轮事实并逐项检查任务目标，供其他插件用 |          |

### 舞台与声音

| 插件                                 | 做什么                                                                     | 默认启用 |
| ------------------------------------ | -------------------------------------------------------------------------- | -------- |
| [舞台画面](./stage.md) `scene-stage` | 更新场景与角色，清理换场前立绘，角色属性可缺省；对白模板可逐段显示完整故事 |          |
| [配乐](./stage.md) `soundtrack`      | 按场景播放世界自带的音乐                                                   |          |

## 四个内置世界

雾港、遥风学园和提灯古冢各示范一种玩法：雾港是阅读模式下的纯叙事调查，遥风学园是舞台模式，提灯古冢是完整跑团。末班地铁是生存沙盒：水位按世界时间倒计时，照明、车门和无线电共用一块电池，调度的命令和乘客手里的照片要逐条核实；它用英文写成，也示范一个世界怎样提供多种语言版本。

| 世界                                | 玩法                   | 值得看的地方                                                             |
| ----------------------------------- | ---------------------- | ------------------------------------------------------------------------ |
| 雾港・裂潮纪 `mistport`             | 阅读模式的暗黑奇幻调查 | 四条带潮汐期限的调查任务、案情板与证据固定、九条隐藏事件与隐藏选项、立绘 |
| 遥风学园・春日薄荷 `haruka-academy` | 舞台模式的校园群像     | 聊天式讲述、日夜场景图、透明立绘、校园作息计时与学园祭任务               |
| 末班地铁 `last-train`               | 现代都市求生，英文写成 | 水位倒计时、共用电池、消息核实、群像支线与人物卡；另有中文版             |
| 提灯古冢・初次远征 `lantern-barrow` | 经典跑团地城探索       | 开局配点、失败时钟与代价结算、道具检定修正、地城与古冢警戒面板           |

想照着它们做自己的世界，文件都在仓库的 [`worlds/`](../../worlds) 目录里。

## 还有更多

生图、语音这类插件不随 Covel 内置，需要另外安装，见[安装插件与世界包](../start/packages.md)。想自己做一个，见[开发插件](../plugins/index.md)。

- **编排与自动推进**：策略选择和委托名额见[会话编排设置](./features.md#会话里的编排设置)；自动推进和停止控制见[故事正在自动推进时](../start/first-session.md#故事正在自动推进时)。
- **群像与主持**：群像对话默认使用玩家身份与点名策略；想亲自当主持人，可在开局准备页关闭角色创建并选“主持人”，或只在**讲述者**设置中选择“主持人（DM）”视角。缺少可用演员或策略插件时，讲述者仍可独自完成故事并交回玩家。详见[群像对话](./story.md#群像对话与角色扮演)。

## 故事驱动的呈现

- **可调面板与外观**：“舞台”风格支持拖动调整阅读剧情栏与舞台回应区的宽度；舞台画面还提供默认关闭的[阅读外观](./stage.md#可选的阅读外观)，可在“菜单 → 本局主题”中切换或恢复默认。详见[舞台模式](./stage.md#舞台模式)。
- **呈现函数与作者扩展**：舞台画面和配乐使用零预算[呈现函数](../reference/plugins.md#presentation-runtimes)，不产生模型调用费用。若要基于内置插件做二次开发，请参阅[输出提交约定](../reference/plugins.md#agent-output-submission)、[接收规则](../reference/world-data.md#data-receivers)与[读取基线冲突](../reference/transactions.md#read-baselines)。
