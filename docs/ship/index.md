# 验证与分发

你的插件或世界在自己电脑上能用了。这一章帮你回答下一个问题：**别人装上之后，也能用吗？**

## 按这个顺序做

| 步骤 | 做什么                            | 读哪一页                          |
| ---- | --------------------------------- | --------------------------------- |
| 1    | 不开游戏，先把插件测一遍          | [测试插件](./test.md)             |
| 2    | 打成安装包，像陌生人一样装一次    | [打包并试装](./package.md)        |
| 可选 | 用真实模型完整跑一遍              | [用真实模型验证](./real-model.md) |
| 3    | 放到 GitHub，让别人用一个链接安装 | [发布与更新](./publish.md)        |
| 4    | 世界和它需要的插件一起发          | [合集](./collections.md)          |

只做世界、不做插件的话，跳过第 1 步：用 `pnpm validate:world` 校验过就可以直接打包。

## 发布前检查清单

- 校验命令通过，没有报错。
- 从安装包装了一次，而不是直接把文件夹拷进去。
- 重启之后数据还在。
- 卸载之后游戏照常运行。
- 包里有一份 `README.md`，写明它做什么、需要哪个版本的 Covel。
- 包里没有密钥、你自己的存档、日志，也没有你电脑上的路径。

## 还想更严格

前两步不调用真实模型，足够发现大多数问题。想在发布前确认真实模型的表现，见[用真实模型验证](./real-model.md)。发布涉及玩家操作流程的改动时，再按[发版前的玩家流程验收](../internals/e2e-testing.md#发版前的玩家流程验收)完整玩一遍。
