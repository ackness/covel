# 雾港·裂潮纪

## 世界设定

雾港夹在悬崖断面和海面之间，像一枚钉进岩壁的铁楔。灰白的浓雾常年不散，空气里永远是盐和铁锈的味道，能见度从不超过五十步。没有人见过雾港的天空——老人们说，上一次雾散还是三代人以前。本地人不道“早安”，只说“雾静”：雾安静下来，说明雾兽还远。

城市顺着崖壁往上分成三层。最高处是**上城**，议会和商会盘踞在崖顶，石砌高墙把雾挡在脚下，议事厅穹顶嵌的远古潮石灯不靠火焰发光。中层是**中港**，码头、工坊、旅店和赌档挤作一团，机械钟塔靠潮汐驱动，每六小时敲一次，这是雾港人唯一的计时办法。最底下是**下潮区**，涨潮时整片沉在灰色海水下，退潮才露出远古文明的遗迹。

没人知道这些遗迹是谁建的。能确定的只有一点：每次退潮露出来的地形都不一样，仿佛海底一直在重新拼自己。验潮师公会管这叫“裂潮”，成因至今说不清。遗迹里散着各种远古遗物：有的能在雾里照出百步远，有的碰一下就让手臂石化，有的夜里会低声说话。遗物贸易是雾港的命脉，也是这座城所有冲突的根子。

更叫人不安的是，雾在变浓。最敏感的验潮师已经察觉，这一年能见度一点点缩短，退潮的间隔一点点拉长。有人说是周期，有人说是预兆，也有人说，雾正醒过来。

## 核心规则

- **裂潮法则**：每次退潮，下潮区露出的遗迹结构都完全不同，从不重复。地图在这里没用，每一次下潮都是瞎摸。退潮窗口一般四到六小时，涨潮来得极快，也说不准时候——涨潮时还留在底下的人，很少回来。
- **雾兽**：雾里住着被叫作“雾兽”的东西，没有固定的样子，被声音和亮光吸引。明火、大声说话、金属碰撞都可能把它们招来。探险者用特制的潮石雾灯（冷光，几乎不出声）代替火把。在下潮区，沉默是第一条活命的规则。
- **遗物鉴定**：远古遗物的效果没法预测，还可能致命。没经验潮师鉴定就擅自使用，是重罪——但黑市上未鉴定的遗物能卖出鉴定品三倍的价，赌的就是这份未知。
- **封潮令**：议会颁的法令，无证平民不得进入下潮区，违者监禁、没收财产。可这法令很难执行：下潮区太大，雾又太浓，议会巡逻队自己都常常在里面迷路。
- **潮力与雾蚀**：极少数人能感觉到海底遗迹传来的某种力量，叫“潮力”，退潮时最强，涨潮时几乎消失。验潮师用手上的“潮纹”引导潮力，把遗物稳住。潮力有代价：用得过头就会“雾蚀”，身体一点点变半透明，最后化进雾里，再也分不清哪部分是人、哪部分是雾。

## 势力格局

**雾港议会**由商会领袖和几家世家组成，控制着上城和合法的遗物贸易。议长陈远山正全力推“封潮令”，对外说是为了平民安全，实际是要掐住遗物的来源——议会自己的探险队不受封潮令约束。议会内部也不是铁板一块：鸽派认为封锁只会把生意推给黑市，鹰派主张用武力清剿盐牙会。至于陈远山到底在想什么，连他的同僚都猜不透：他那支私人探险队下去的次数，远远不止“维护治安”需要。

**验潮师公会**是唯一有资格鉴定远古遗物的学术组织，靠议会拨款过日子，名义上还算独立。公会长齐老是个温和的老学者，心思更多在学问上，不在政治上。可公会里年轻的验潮师越来越坐不住：他们在遗迹里看到了些东西，而上面似乎在有意压下某些鉴定报告。“潮力不存在，只是迷信”，这是公会的官方说法，可越来越多的学徒在退潮深处听见了不该听见的东西。

**盐牙会**把持下潮区的非法遗物贸易，根扎在底层。二当家铁姑用铁腕维持秩序，却给手下立了一条谁都不能破的规矩：绝不把没鉴定过的危险遗物卖给不知情的平民。盐牙会同议会长期冷战，互相渗透，偶尔在巷子里动刀，谁也吃不下谁。底层有句话：铁姑攥着黑市，图的不是钱。

**雾中教会**是近几年冒出来的神秘组织，拜的是“雾之主”。他们相信雾本身有意识，下潮区的遗迹是“雾之主的身体”。教会向底层贫民传一套说法：雾蚀不是诅咒，是升华。走投无路的人涌进去不少。议会骂它是邪教，可它的信众涨得叫人不安——尤其是年轻的“雾使”小霜一次次说准了退潮的时间和遗迹的位置之后。

## 关键人物

- **林远舟**：验潮师公会的新学徒，刚过初试，做事谨慎，好奇心却压不住。考完试以后他总像有心事，问起来只说没睡好。玩家若是新学徒，他是公会里年纪最近的那个同侪；玩家若是潮民，他是新认识的一个公会帮手。也可能，是他第一个把玩家拖进那些“不该知道的事”。
- **苏窈**：已经出师的验潮师，齐老的助手；玩家参加过入门考核，她就是当场的监考官。她做事一丝不苟，对公会一向忠诚，齐老失踪之后，才开始怀疑自己一直相信的东西。她是玩家和公会高层之间的那道门，很多线索要经过她的手——但她知道的，总比说出口的多。
- **铁姑**：盐牙会二当家，三十出头，左臂从肘部往下在一次遗物事故里中了雾蚀，半透明地泛着灰光。她冷硬，守信，是底层秩序真正撑着的人。她一直高价收某一类遗物碎片，价出得不像做买卖——收去做什么，她不说。
- **陈远山**：议会议长，六十多岁，权术玩得很熟。面上推封潮令是为了公共安全，私下却派亲信探险队一次次往深处走。他到底在找什么？知道答案的人，不是闭着嘴，就是已经不在了。
- **齐老**：验潮师公会长，白发的温和学者，对裂潮的了解比任何活人都深。最近他总戴着手套。故事开场，他留下一封信就进了下潮区，而那时正是涨潮期，没有谁能在涨潮期进得去。
- **小霜**：雾中教会最年轻的“雾使”，不过十五六岁。她说自己听得见雾的“低语”，还几次说准了退潮的时间和遗迹的位置。先知、疯子，还是骗子？她看玩家的那一眼，像是早就认得。
- **灰隼**：陈远山私人探险队的队长，也是封潮令最锋利的那只手。他话少，下手准，不带多余情绪，奉命去封某片区域、搜某个型号的遗物、抓几个“从没听说过的人”。他最近追查的方向，正对着齐老消失的地方。

## 玩家身份与群像入口

玩家不是预言里唯一的救世主，只是让这七个人原本的轨迹偏了一点的新变量。开局可以自然接上两种身份：

- **新晋验潮师学徒**：腕上留着考核的浅潮纹，手边有验潮师公会的潮石雾灯与见习查档凭证；苏窈是监考官，林远舟是同期。你能合法进公会塔，代价是得服从封档和鉴定的规矩。
- **熟悉下潮区的潮民**：知道褪水阶、栈桥暗门与雾灯手势，随身带着冷光旧雾灯与水防铅封布；齐老曾替你或你的家人免费鉴定过一件遗物，失踪前留下便笺请苏窈寻找“一个肯记路、不迷信地图的人”。你没有许可证，却更容易接触盐牙会与雾中教会。

不管你是哪种身份，苏窈在主栈桥找到你时，手里都只有半封信。另外半封信、齐老真正走过的路线、深退潮为什么提前，要从几个人各自的利益缝隙里一点点拼。林远舟需要有人替他守住潮感的秘密，铁姑要抢在陈远山前面把钥匙拼齐，灰隼要弄清楚自己执行的命令有没有被人改过，小霜想知道你是不是真的“也听得见”。这些人会主动要你答应什么，会拒绝不合自己立场的事，也会因为你守信、撒谎、受伤、做过的选择改变对你的信任和所在的地方，不会站在原地等你回去交任务。

## 插件与世界扩展协同

- **纯叙事与无好感/无掷骰/无背包边界**：本世界仅通过 `pack:traditional-story` 与 `data/` 约定接入故事事件、核心任务（`core-quest`）、记忆（`clues` / `commitments` / `relics` / `tides`）、世界规则（`tide-mystery`）与世界时间，不启用 `dice-check`、`inventory` 或 `affinity` 插件。切勿在叙事里伪造检定掷骰数字、独立背包物品栏或好感档位名；随身雾灯、封档副本、遗物碎片与通行许可一律写在角色资料的 `equipment` / `relics` / `permit` 与叙事描写里，人物亲疏写在角色 `trust`（0–100）与 `dispositionToPlayer`。
- **维度与任务联动**：`caseBoard` 记录线索的 `unverified` / `corroborated` / `contaminated` / `resolved` 与来源、矛盾、`secured`；`deepWithdrawal` 沿 `triple-warning` → `step-ninety` → `full-exposure` → `return-bell` → `flood` → `receded` 单向推进，进入 `flood` 时回声廊任务 `echo-gallery-traces` 的截止线（`deadline`）会自动触发“来不及固定记录”。`factionStanding` 与 `keyFragments` 仅结算本轮叙事中已发生并被知晓的变化。
- **按需词条与细节调用**：无声栈、盐市、静潮病院病房记录、议会鹰鸽两派以及雾蚀早期征兆均由 `lorebook` 按关键词触发，不必在单回合里一次性灌输给玩家。

## 开局线索板与状态推进

最初四条线索彼此咬合，但哪一条单独拿出来都证明不了结论：

- **半封信**在苏窈手里，上面写着“钥匙不能落到他手里”。纸边沾着只在退潮遗迹里才结晶的黑潮盐，可有人看见齐老是在满潮时离开的。
- **第七十四号鉴定报告**从公会封档库少了一页，目录仍写着“铰齿状灰色碎片”；同日访客簿也被无损取页。
- **回声廊的三种痕迹**分别属于齐老的潮纹、灰隼私队的新绳索，还有一块刻着童谣的铜片。三样东西留下的时间对不上，得比对潮线和证词。
- **静潮病院的幸存者**是三年前那支深潜队唯一回来的人。议会把他隔离起来，他只会说“它在下面醒了”，可病房记录显示，他最初说的并不是这句话。

线索会经历“未核实、已佐证、已污染、已解决”。找到物证只是未核实；有了独立证词或潮纹记录，才算已佐证；被涨潮冲坏、被伪造，或者被捅出去，就成了已污染。潮水冲走证据，并不等于替谁的说法作证。

深退潮的推进是这样的：先是三连预警，海水退过褪水阶第九十级，遗迹完全露出来，然后返潮警铃响起，海水急涨。警铃之后一般只剩半小时撤离。每次绕过检查、动用遗物、接下许可证、欠下暗门的人情，都该留下至少一样看得见的后果：潮时往前推了、地点变了、体力或压力起落、雾蚀加深、人物态度变了、阵营许可或通缉升级、线索可信度变了。

雾蚀不可逆，只能按程度看：二十五以下多半只有畏寒、耳鸣这类说不清的小症状；二十五到四十九，身上开始出现局部的半透明；五十到七十四，能感觉到的潮力更强，人却会持续使不上力；七十五以上，随时可能化进雾里。休息能回体力、降压力，降不了雾蚀。

## 故事主线

故事不逼你走一个结局，但天然分成三个阶段，越往深里走，代价越大：

1. **退潮序章**：一次罕见的深退潮就要来了。玩家以验潮师学徒（或潮民）的身份卷进齐老失踪的事，在议会、公会、盐牙会和教会之间找他的下落，同时学会在雾里活下去。
2. **碎片之争**：玩家慢慢拼出一个事实：齐老的失踪、铁姑收的碎片、陈远山在找的东西，指向的是同一件东西——一把能打开下潮区最深处的“钥匙”。四方开始抢，玩家必须站边，每一次站边都会留下收不回来的代价：人情、雾蚀、信任，甚至性命。
3. **雾之主醒来**：雾越来越浓，周期逼到临界点。玩家最终会碰到那个所有人都不肯说的真相：下潮区深处有东西正在醒。拦下它、叫醒它，还是和它一起活下去，取决于这一路上做过的所有选择。

## 暗线与悬念

- 下潮区最深处从来没被人到过。上一次深退潮，探险队带回来一块遗物，上面刻的字和雾港建城碑文一模一样，可碳测定显示，它比雾港早了一万年。
- 过去一年，雾蚀患者翻了三倍，官方不认。齐老的私人笔记里留着一句：“雾在变浓。每十年浓一次。我们正处在某个周期的临界点。”
- 铁姑收的遗物碎片，看着像一把“钥匙”的零件。这钥匙能开什么？她不说。可议长陈远山在找同样的东西，灰隼的搜查清单上也有它。
- 三年前，一支议会探险队进了下潮区，整队失踪，唯一回来的那个人疯了，只会翻来覆去说一句：“它在下面醒了。”那个活人，现在关在哪？
- 小霜为什么每回都说中？是雾真的在对她说话，还是有人借她的嘴说话？她第一次见玩家时说的那句“你也听得见，对吗”，到底是什么意思？
- 齐老从未公开用过潮力，为何会雾蚀？如果不是潮力，还有什么能让一个人慢慢溶进雾里？
- 这些人的底细，故事没揭开之前不要直说：齐老是少数知道“裂潮”真相的人，他选择了闭嘴，手上已经露出雾蚀的征兆；铁姑做过验潮师学徒，这是她最大的秘密；林远舟在考核里发现自己能微弱地感觉到潮力，谁也不敢讲，因为公会的官方立场是潮力不存在；灰隼已经开始怀疑命令背后的东西。

## 开局情境

黄昏，你踩上中港主栈桥湿滑的木板。渡船的缆绳没进浓雾里，人像从什么都没有的地方走过来。空气咸腥，压在胸口。远处钟塔闷闷地响，不是平常报时的敲法，是三下急促的连击。码头上的老水手停下手里的活，互相看着。

三连击是“深退潮预警”。这种事极少见，上一次还是六年前，那次露出一座被叫作“骨拱门”的巨大结构，也带走了十七条人命。

栈桥上很快分出两股人。盐牙会的人缩在暗处招胆大的探险者，许下厚酬。议会巡逻队在贴紧急封潮令，警告无证进下潮区的人都得进牢。

一个穿验潮师公会制服的年轻女人从人群里挤过来，脚步很急。你参加过入门考核，就认得出她是监考官苏窈；你是潮民，就看见她袖口露出的便笺上写着齐老留给你的那个称呼。她脸色不好。

你是新学徒，她的目光就先落在你腕上的考核潮纹；你是潮民，她从袖子里摸出齐老留给你的便笺。

“齐老失踪了。”她没等你开口就压低声音，“今天早上他留下一封信就走了，信上说他去了下潮区——可那时是涨潮期，没有人能在涨潮期进下潮区。”

她朝钟塔那边瞥了一眼：“可要是深退潮真的来了……”

钟塔按老例只敲三响，今天却在余音未绝时沉重地多敲了第四下——像有什么东西在水底推了齿轮一把。地面轻轻震了一下。码头边的海水看得见地往后退，底下露出泛着灰光的轮廓，是从没人见过的遗迹。

雾里，好像有什么东西睁开了眼睛。
