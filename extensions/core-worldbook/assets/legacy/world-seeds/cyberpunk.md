# 霓虹深渊：2187

## 世界背景

2187 年的全球秩序由五大超级企业主导。政府已沦为傀儡，企业通过神经链、信息审查和义体改造控制社会运行。新上海被划分为云端区、中层区、底层区和地下区，阶层断裂极其明显。

## 核心设定

### 神经链

- 提供网络接入、身份认证、AR HUD 与生命体征监测。
- 高阶版本带来优势，也引入被入侵和被控制的风险。

### 义体改造

- 战斗型、隐匿型、工程型义体广泛存在。
- 人性值是关键成本，过度改造可能诱发赛博精神病。

### 黑客技术

- 可用于系统入侵、情报窃取与战斗黑客。
- 幽灵协议类能力适合未来做成专门 package 或 command surface。

## 势力

- 天枢科技：掌控神经链与脑数据。
- 铁幕军工：武装与安保霸主。
- 永生医药：义体与延寿技术垄断者。
- 量子通讯：信息流与审查中心。
- 极乐集团：娱乐和消费控制。
- 地下网络：反企业黑客联盟。

## 核心冲突

- 神经链后门：谁都可能被远程关闭。
- AI 觉醒：地下网络出现不受控智能迹象。
- 底层暴动：社会秩序随时失控。
- 人性边界：人还是不是人，成为世界级命题。

## DM 指引

### 叙事风格

- 采用 noir 气质、霓虹雨夜与道德灰区。
- 强调情报、交易和代价，而不是单纯火力对轰。

### 运行时拆分建议

- 企业、区域、技术体系：归入 `worldbook`
- 冷硬、克制、功利化主持语气：可归入 `persona`
- NPC 声望、装备、义体状态：先作为 `MemoryDocument`，未来再升级到角色卡实体

## 重要 NPC 种子

- 老鬼：底层情报贩子。
- Dr. 林：非法改装医生。
- 零：地下网络核心黑客。
- 妈妈桑：中立酒吧经营者与社交枢纽。
