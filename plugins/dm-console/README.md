# dm-console

公开会话控制台，不含运行时、入口、模型槽或依赖。通过顶部插件视图菜单选择 `dm-console`，不改变身份、视角、策略或默认视图。

- `PLUGIN.md`：声明 `contributes.ui.view`。
- `ui/dm-console.json`：用公开组件组合在场角色、待处理交互、故事和输入框。
- `locales/zh.yaml`、`locales/lock.json`：中文标签和翻译锁。

在场角色只来自公开 `stage.cast@1`，不是全部人物或行动资格清单；没有提供方时显示空状态。待处理交互只含玩家已看到、尚未回答且未过期的表单、选择和确认，不读隐藏剧情。故事不含执行详情或推理。

输入框复用宿主草稿、队列和行动目录：主持人可以选择导演指示、旁白或推进，旁观者只能推进，玩家使用其普通模式。推进不发占位文字。输入经普通行动/交互校验并在提交成功后持久化。打开页面不运行模型；行动费用取决于已选叙事和辅助提供方。

主持人与旁观方案请求此插件，群像对话仅推荐。普通主持人不委托 NPC；主持人控制群像需要自己选择身份、策略和相应提供方。已有会话可手动启用，不自动追加入旧选择。

## 验证

在仓库根运行 `pnpm validate:plugin plugins/dm-console`。真实声明加载、宿主渲染和浏览器回归位于 plugin-loader、Web、server 和 `tests/e2e/bundled-views.spec.ts`，本包没有测试或服务器脚本。
